# 微信公众号复制兼容性

这份说明记录已经在实际公众号后台验证过的图片与复制规则，供 Agent 生成公众号版 HTML 时调用。

## 图片路径怎么选

| 图片位置 | 推荐方式 | 结果 |
|---|---|---|
| 只在本地、没有服务器权限 | **Base64 内嵌（C）** | 图片随浏览器富文本选区一起粘贴，不用上传服务器或素材库 |
| 已部署到自有、无防盗链的 HTTPS 静态目录 | 公网 `<img src="https://...">`（A） | 公众号通常会自动抓图，粘贴后要检查是否全部进入 |
| 飞书、带防盗链 CDN 或无法下载的图片 | 占位块（B） | 手动上传素材库，再替换占位块 |

### 本地图片一键内嵌

```bash
python scripts/embed_images.py article.html article_base64.html
```

脚本会以内嵌 `data:image/...;base64,...` 替换相对路径和 `file://` 图片；远程 URL、`vscode-cdn://` 和已有 Base64 原样保留。默认输出新文件，不覆盖源文件。输入 HTML 应包含 `<meta charset="utf-8">`，并且 meta 放在正文容器之前，避免 Base64 长串挤出浏览器编码探测窗口导致中文乱码。

Base64 会使体积增加约 1.37 倍。整篇 HTML 尽量控制在 3MB 左右；过大时先把图片转 JPEG、宽度限制在约 1400px，或降低质量。封面图仍在公众号后台单独上传。

## 复制到公众号

1. 用 Chrome 或 Edge 打开生成的 HTML（不要从 VS Code 预览面板复制，预览面板可能把图片地址改成 `vscode-cdn://`）。
2. 点击页面的「复制到公众号」或「一键复制全文」按钮。
3. 在公众号正文编辑器粘贴，并扫一眼确认每张图都已进入；偶发抓取失败时重新粘贴一次。

复制按钮和脚本必须位于正文容器之外，复制目标只选正文容器；这样不会把按钮、脚本或工具栏带进公众号。

## 其他高频兼容规则

- 可视化直接复制优先使用纯文档流；并排布局用堆叠或显式边框的表格，不依赖 `inline-block` 块并排。
- 表格使用 `border-collapse:collapse`，每个单元格显式写边框；表头避免深色底配白字，公众号可能统一同行文字颜色。
- 正文段落建议 16px 起，章节主标题约 18px，层级相邻至少差 2px；横向 padding 尽量不超过 16px，避免嵌套双层留白。
- 中文正文使用成对弯引号；属性、URL、代码块中的英文引号保持原样。
- 正文图片放在复制目标容器内；本地图片必须先内嵌或明确改成占位块，不能把相对路径直接交付。
