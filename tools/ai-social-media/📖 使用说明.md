# AI新媒体工具包 使用说明

> **给人类用户看的说明文档**。如果你是AI，请看 `给AI的安装指令.md`。

## 这是什么

**AI新媒体工具包**，精选6个开源 Agent Skill，覆盖新媒体内容生产的核心环节。

这些Skill来自GitHub开源社区和内部开发，经过筛选和整合，帮助内容创作者提升效率：

| Skill名称 | 功能 | 来源 | 开源协议 | Star数 |
|---------|------|------|---------|--------|
| **guizang-social-card** | 小红书3:4图/公众号21:9+1:1封面生成 | [op7418/guizang-social-card-skill](https://github.com/op7418/guizang-social-card-skill) | AGPL-3.0 | 5196⭐ |
| **gzh-design** | 微信公众号文章排版引擎 | 甲木 × 摸鱼小李（内部工具） | AGPL-3.0 | - |
| **ffmpeg-usage** | FFmpeg视频处理工具包 | [ychoi-kr/claude-ffmpeg-skill](https://github.com/ychoi-kr/claude-ffmpeg-skill) | MIT | 27⭐ |
| **ai-radar** | AI情报雷达（日报/周报/月报） | [songshishuang/ai-radar-skill](https://github.com/songshishuang/ai-radar-skill) | MIT | 1⭐ |
| **videocut-clip-oral** | 口播视频剪辑 | [Agentchengfeng/chengfeng-videocut-skills](https://github.com/Agentchengfeng/chengfeng-videocut-skills) | Apache-2.0 | 2691⭐ |
| **videocut-finish** | 口播视频成片 | 同上 | Apache-2.0 | 同上 |

## 适用场景

### 1. 社交媒体内容生产

**guizang-social-card** — 小红书图文/公众号封面

- 支持小红书3:4竖图、公众号21:9+1:1封面对、文章配图
- 内置28种布局、10种主题预设
- 两种视觉风格：电子杂志风（衬线字体+流体背景）、瑞士国际主义风（无衬线+极简网格）
- 从文章、产品笔记、截图等素材一键生成精美封面
- **注意**：使用AGPL-3.0协议，商业使用需遵守开源义务

**触发示例**：
- "帮我做一个小红书封面图，主题是xxx"
- "把这篇文章做成公众号封面"
- "生成一套小红书轮播图"

**gzh-design** — 微信公众号文章排版

- Markdown/Word/PDF转公众号可直接粘贴的HTML
- 多主题风格库（摸鱼绿/红白/石墨极简/留白禅意/票据风/橄榄手记等）
- 自动章节编号、关键词下划线标记、引言卡片、目录导航
- 支持代码块、图片/GIF、表格等元素
- 校验脚本确保平台合规
- **注意**：使用AGPL-3.0协议，商业使用需遵守开源义务

**触发示例**：
- "帮我排版这篇公众号文章"
- "把这个Markdown转成公众号HTML"
- "用摸鱼绿主题排版这篇文章"

### 2. 视频素材处理

**ffmpeg-usage** — 通用视频/音频处理

- 格式转换（MP4/WebM/MOV/GIF等）
- 视频裁剪、拼接、压缩
- 音频提取、格式转换
- 添加字幕、水印
- 调整分辨率、帧率、速度
- 批量处理

**触发示例**：
- "把这个视频转成GIF"
- "把视频压缩到10MB以内"
- "提取这个视频的音频"
- "把视频横屏改成竖屏9:16"

### 3. 口播视频制作

**videocut-clip-oral + videocut-finish** — 口播视频全流程

- **剪辑阶段**：自动识别口误、重复、语气词、静音段，生成审核页确认后物理剪切，输出剪后字幕
- **成片阶段**：分镜规划、动画设计、时间线编排，分别给你审核
- 适合教程、产品演示、个人vlog等口播类内容
- **注意**：首次使用需下载 chengfeng-videocut Runtime（约几十MB），AI会自动提示

**触发示例**：
- "使用剪口播处理这条视频"
- "把剪好的视频做成成片"

### 4. AI行业资讯跟踪

**ai-radar** — AI日报/周报/月报生成

- 零API key、零部署，直接用
- 聚合OpenAI/Anthropic/Google/Meta等厂商官方源 + HackerNews + 行业媒体 + 关键人物
- 自动按重要度评分（1-10）、8类分类、实体标注
- 支持4种视角：PM / 工程师 / 投资人 / 研究员
- 输出中文简报，2分钟读完

**触发示例**：
- "今天AI圈有什么"
- "给我生成一份AI周报"
- "最近AI有什么重要动态"
- "从工程师视角生成AI月报"

## 怎么发给同事

### 方法1：发整个文件夹

把 `AI新媒体工具包/` 整个文件夹发给同事，让他们：
1. 把 `给AI的安装指令.md` 文件丢给自己的AI（Claude Code / Codex / ChatGPT等）
2. AI会自动读取并安装（如果支持Skill机制），或者提示手动操作步骤

### 方法2：只发 skills 子文件夹

如果同事已经懂怎么装Skill，直接发 `skills/` 文件夹，让他们复制到 `.claude/skills/` 或 `.agents/skills/` 即可。

## 怎么用

### 如果你用 Claude Code / Codex（推荐）

**最简单：直接对话触发**

安装后，直接用自然语言触发即可：

```
你："今天AI圈有什么"
AI：（自动调用 ai-radar skill，生成日报）

你："帮我把这个视频转成GIF"
AI：（自动调用 ffmpeg-usage skill，执行转换）

你："做一个小红书封面，主题是春季穿搭"
AI：（自动调用 guizang-social-card skill，生成封面）
```

**明确指定Skill（当AI没自动识别时）**

如果AI没自动调用，可以显式指定：

```
你："使用 ai-radar skill 生成今天的AI日报"
AI：（强制调用 ai-radar）
```

### 如果你用 ChatGPT / Gemini / 其他AI

这些AI不支持Skill机制，需要手动操作：

1. 打开对应Skill的 `SKILL.md` 文件（在 `skills/xxx/SKILL.md`）
2. 复制 `---` 分隔符之后的全部内容（不要复制开头的YAML部分）
3. 粘贴到AI的自定义指令 / 对话开头
4. 然后再提问

**示例（ChatGPT）**：
1. 打开 `skills/ai-radar/SKILL.md`
2. 复制内容，粘贴到 ChatGPT 设置 → 自定义指令
3. 之后每次说"今天AI圈有什么"，ChatGPT就会按照指令生成日报

## 6个Skill详细说明

### 1. guizang-social-card（歸藏社交卡片）

**适合人群**：小红书博主、公众号运营、内容创作者

**核心功能**：
- 小红书3:4竖图（含轮播图）
- 公众号封面对（21:9主图 + 1:1方图）
- 文章配图、产品卡片

**两种视觉风格**：
- **电子杂志风**（默认）：衬线字体 + WebGL流体背景 + 暖色调，适合人文分享、行业观察
- **瑞士风**：无衬线字体 + 极简网格 + 高反差色（克莱因蓝/柠檬黄/柠檬绿/安全橙），适合科技产品、数据汇报

**输入素材**：文章、产品笔记、截图、照片都可以

**输出格式**：单文件HTML → AI自动转PNG图片

**局限性**：
- 不适合纯摄影展示类内容（如美食大片、OOTD全身照）
- 不适合Y2K/哥特萝莉/kawaii等装饰风美学
- AGPL-3.0协议，商业使用需开源修改（如果你修改了代码并对外提供服务）

### 2. gzh-design（公众号排版引擎）

**适合人群**：公众号运营、内容创作者、需要专业排版的博主

**核心功能**：
- **多格式输入**：Markdown（推荐）、Word(.docx)、PDF、纯文本
- **多主题风格**：摸鱼绿（清单/工具盘点）、红白色系（深度分析）、石墨极简（科技评论）、留白禅意（深度随笔）、票据风（工具对比）、橄榄手记（案例复盘）等
- **智能处理**：自动章节编号、正文关键词下划线标记、引言关键词高亮、目录提取
- **完整组件**：引言卡片、章节标题、代码块、图片/GIF、表格、引用、作者签名
- **平台合规**：内置校验脚本，确保样式在公众号编辑器粘贴后不丢失
- **一键自动排版**：可完全自动推断结构+选主题+排版，无需确认

**工作流程**：
1. 给AI一篇文章（Markdown/Word/PDF都行）
2. AI推荐适合的主题风格（或你指定）
3. 生成HTML文件 + 带「复制」按钮的预览页
4. 打开预览页，点右上角「复制到公众号」按钮
5. 到公众号编辑器粘贴（Ctrl/⌘+V），完成

**输出格式**：
- 干净正文HTML（用于校验和手动粘贴兜底）
- 带复制按钮的预览页（一键复制到剪贴板）

**局限性**：
- 主要面向图文内容，不适合纯图片展示类推文
- AGPL-3.0协议，商业使用需遵守开源义务

### 3. ffmpeg-usage（FFmpeg工具包）

**适合人群**：视频剪辑师、自媒体创作者、需要批量处理视频的人

**核心功能**：
- **格式转换**：MP4/WebM/MOV/AVI/MKV互转，视频转GIF
- **编辑操作**：裁剪片段、合并视频、调速度、旋转、镜像
- **画面调整**：改分辨率、改宽高比、裁切画面
- **音频处理**：提取音频、去音频、调音量、音频格式转换
- **字幕水印**：烧录字幕、添加水印、去水印
- **压缩优化**：压缩体积、平台优化（抖音/B站/YouTube等）
- **批量处理**：一次处理多个文件

**优势**：不依赖在线服务，纯本地处理，速度快、无隐私泄露

**前提条件**：本机需安装 ffmpeg（AI会检测，没装会提示安装命令）

### 4. ai-radar（AI情报雷达）

**适合人群**：AI从业者、产品经理、投资人、技术研究者

**核心功能**：
- **零成本**：不需要API key，不需要部署服务器
- **覆盖全面**：OpenAI/Anthropic/Google/Meta官方源 + HackerNews + HuggingFace + TechCrunch/TheVerge等媒体 + X关键人物
- **智能筛选**：按重要度1-10评分，过滤水文
- **多视角**：PM视角、工程师视角、投资人视角、研究员视角
- **中文输出**：结论先行，2分钟读完

**使用方式**：
- 日报（默认）："今天AI圈有什么"
- 周报："这周AI有什么重要动态"
- 月报："给我生成一份AI月报"
- 指定视角："从工程师视角生成AI日报"

**两种工作模式**（AI自动判断）：
- **连接模式**：如果你自己部署了AI情报站实例，AI会直接拉取已生成的报告
- **独立模式**（默认）：AI现场抓取源 + 现场加工生成

**局限性**：
- 主要覆盖国外AI动态，国内AI源较少
- 首次运行较慢（需抓取几十个源）

### 5. videocut-clip-oral（口播剪辑）

**适合人群**：做教程、产品演示、vlog、知识分享的创作者

**核心功能**：
- 自动识别口误、重复、语气词（嗯、啊、那个等）、静音段
- 生成审核页（网页形式），你勾选要删的部分
- 确认后物理剪切视频
- 输出剪后字幕文件（.srt）

**工作流程**：
1. 你给AI一个口播视频
2. AI调用Skill，识别出所有口误/重复/静音
3. 生成审核页（一个本地网页），你打开检查
4. 勾选确认要删除的部分
5. AI执行剪切，输出 `source_cut.mp4` + `subtitles.srt`

**前提条件**：
- 首次使用需下载 chengfeng-videocut Runtime（AI会自动提示并下载）
- 需要安装到 `~/.chengfeng-videocut/`

### 6. videocut-finish（口播成片）

**适合人群**：同上

**核心功能**：
- 基于剪辑后的素材（`source_cut.mp4` + `subtitles.srt`），制作完整成片
- 分镜规划（镜头切分、节奏设计）
- 动画设计（转场、字幕动画、图表动画）
- 时间线编排（音乐、音效、特效）
- 每个环节都生成审核页，你确认后再执行

**工作流程**：
1. 先用 `videocut-clip-oral` 剪好视频
2. 对AI说"使用口播成片把剪好的视频做成完整成片"
3. AI生成分镜方案 → 你审核
4. AI设计动画效果 → 你审核
5. AI编排时间线 → 你审核
6. 最终输出成片 `final.mp4` + 验证报告 `verification.json`

**注意**：
- 这个Skill依赖 `videocut-clip-oral` 的输出，必须先剪辑后才能成片
- 也依赖 chengfeng-videocut Runtime

## 常见问题

### Q1: 我的AI不支持Skill怎么办？

A: 改用手动粘贴方式。打开对应Skill的 `SKILL.md` 文件，复制内容粘贴到AI的自定义指令或对话开头。具体步骤见 `给AI的安装指令.md`。

### Q2: AI没有自动调用Skill怎么办？

A: 可以显式指定，例如："使用 ai-radar skill 生成今天的AI日报"。或者检查是否安装正确（重启客户端试试）。

### Q3: videocut的两个Skill报错说"Runtime未安装"

A: 正常现象。首次使用时AI会提示下载 Runtime（一个视频处理工具），按提示操作即可。如果你不做口播视频，可以不装这两个Skill。

### Q4: guizang-social-card 生成的图片版权归谁？

A: 
- 你输入的素材（文字、照片）版权归你
- 生成的图片版权归你
- 但如果你修改了 guizang-social-card 的代码并对外提供服务（比如做成网站让别人用），需要开源修改后的代码（AGPL协议要求）
- 如果你只是自己用，或者用它生成图发到小红书/公众号，没有修改代码，不受影响

### Q5: ai-radar 的信息准确吗？

A: ai-radar 只是抓取和聚合工具，信息准确性取决于来源（OpenAI官网、HackerNews等）。AI会自动标注来源链接，建议点进去核实重要信息。

### Q6: 这6个Skill够用吗？还有别的推荐吗？

A: 这6个是从几十个新媒体相关Skill中精选出来的，覆盖了最核心的场景。如果你有特殊需求，可以：
- 去 GitHub 搜索 "claude skill" + 你的关键词
- 访问 [Anthropic Skills 官方仓库](https://github.com/anthropics/skills)
- 自己写Skill（参考现有Skill的 `SKILL.md` 格式）
