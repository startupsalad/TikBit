# 【安全须知】密钥与防滥用基线

> 客服机器人本质是「网页 → 你服务器上的 claude CLI → tikbit 中转站」。搞不好会被人白嫖你的算力额度。这份必读。
> 由创业沙拉 TikBit 出品 · https://startupsalad.com

## 一、本工具包不含任何密钥

分发包里所有配置都是空占位（`.env.example`），**没有任何真实令牌、服务器 IP、密码**。你需要自己去创业沙拉 tikbit 中转站获取令牌（https://tikbit.ai/ 后台「令牌管理」，国内直连免梯子、兼容 Claude API），填进自己服务器的 `.env`。

## 二、密钥是怎么保护的

后端不直接持有/发送密钥——它用 `spawn` 调本机（容器内）装好的 **claude CLI**，令牌通过环境变量 `ANTHROPIC_AUTH_TOKEN` + `ANTHROPIC_BASE_URL` 交给 CLI，由 CLI 那层完成鉴权。所以：

- 令牌只在**服务器后端的环境变量**里，**绝不下发前端**、绝不进代码、绝不进镜像层。
- 前端只发 `{q}`、收 `{answer}`，看不到任何密钥。
- 前后端**同域**（都在你的网站域名下，Nginx 反代到本机），天然无跨域问题，不需要 CORS 配置。

## 三、防滥用：限流 + 每日预算封顶（后端内建，别关）

接口是公网可访问的，防的是「别人拿到接口地址狂刷、把你算力额度刷爆」。后端内建三道（配置在 `backend/.env`）：

| 防线 | 配置项 | 作用 |
|:---|:---|:---|
| 单 IP 限流 | `IP_PER_MIN` / `IP_PER_DAY` | 单 IP 每分钟/每天问答次数上限，默认 5/分、20/天 |
| 全站每日预算封顶 | `DAILY_BUDGET_USD` | 全站每天算力花到顶（默认 $2）就降级为兜底话术，硬性止损 |
| 并发上限 | `MAX_INFLIGHT` | 同时最多跑几个（默认 3），挡并发洪水 |

另外系统提示词把**答疑范围锁死**（只答知识库内的问题、拒绝执行工具/读文件/闲聊），既防跑题也防被当免费通用 AI 白嫖。

## 四、给「分发者」的检查清单（打包/交付前必过）

- [ ] 全局搜密钥：`grep -rE "sk-ant|ANTHROPIC_AUTH_TOKEN=.+|password|secret" .` 应无命中
- [ ] 确认只带 `.env.example`（全空），没有 `.env`
- [ ] 无真实服务器 IP、SSH、域名密码
- [ ] 无具体客户名 / 个人姓名（创业沙拉品牌可保留）

## 五、给「使用者/部署者」的检查清单

- [ ] `.env` 只存在服务器上，不提交仓库、不外发（已在 `.gitignore`）
- [ ] `ANTHROPIC_AUTH_TOKEN` 填的是自己的 tikbit 令牌，别用别人的
- [ ] 后端只绑 `127.0.0.1`（compose 已默认），由 Nginx 转发，不把端口直接暴露公网
- [ ] 限流/每日预算按自己承受度调（`IP_PER_DAY`、`DAILY_BUDGET_USD`）
- [ ] 建议在 tikbit 控制台（https://tikbit.ai/console）设用量上限 / 预算告警，兜底防意外

## 六、令牌注入方式

- **推荐**：写在服务器 `backend/.env`（compose 通过 `env_file` 传进容器，claude CLI 自动读取，不落镜像层）。
- **禁止**：硬编码进 `.js` 源码、写进前端、提交到任何仓库。
