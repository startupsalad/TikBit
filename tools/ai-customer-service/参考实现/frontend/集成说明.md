# 前端聊天窗口 · 集成说明

把客服窗口挂到你的网站上，只需要一行代码。

## 方式一：一行 script 引入（推荐）

1. 把 `chatbot-widget.js` 上传到你的网站能访问到的路径（如 `/assets/chatbot-widget.js`）。
2. 在**每个想显示客服的页面** `</body>` 前加一行：

```html
<script src="/assets/chatbot-widget.js"
        data-api="/guide-api/ask"
        data-title="在线咨询"
        data-subtitle="只答产品使用相关，复杂问题请联系我们"
        data-welcome="你好，有什么可以帮你？"
        data-fallback="咨询暂时连不上，请稍后再试或联系我们。"></script>
```

脚本会自动在右下角生成 💬 悬浮按钮，点击弹出聊天窗口。不冲突现有页面样式（类名统一 `ssc-` 前缀 + 超高 z-index）。

## 配置项（data-* 属性）

| 属性 | 必填 | 说明 |
|:---|:---:|:---|
| `data-api` | 是 | 问答接口地址，相对路径，需与 Nginx 反代路径一致（如 `/guide-api/ask`） |
| `data-title` | 否 | 面板标题，默认「在线咨询」 |
| `data-subtitle` | 否 | 标题下的小字说明 |
| `data-welcome` | 否 | 首条欢迎语 |
| `data-fallback` | 否 | 服务连不上时的兜底话术（换成你的联系方式最好） |
| `data-accent` | 否 | 主题色，默认创业沙拉红 `#de283b`，可换成你的品牌色 |

## 方式二：手动嵌入 HTML

如果你不方便加 script 标签（比如某些建站平台），可以把 `chatbot-widget.js` 的内容直接贴进页面的 `<script>` 块，并在开头手动改 `CFG` 里的默认值。

## 请求协议

前端向 `data-api` 发 `POST`，body 是 `{"q":"用户的问题"}`，后端返回 `{"answer":"回答"}`。单轮问答（不带历史），与后端保持一致。

## 安全边界（怎么防被刷）

前端 widget 和后端**同域**（都在你的网站域名下，通过 Nginx 反代到本机后端），所以不需要跨域配置。防滥用靠**后端内建的限流 + 每日算力预算封顶**（单 IP 每分钟/每天次数上限、全站每日预算到顶降级），配置在 `backend/.env`。详见 `docs/【安全须知】API密钥与鉴权基线.md`。

## 本地预览

打开 `demo.html` 可以看窗口长相（未连后端，发消息会走兜底话术，属正常）。
