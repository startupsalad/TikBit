## 它能干嘛

给你的网站右下角加一个 💬 悬浮按钮，访客点开就能提问，AI 基于你提供的资料即时回答。像很多官网上的「在线客服」，只不过背后是 Claude AI，答得更聪明，还不用请人守着。

## 最省心的用法：让 AI 帮你装

如果你在用 Claude、CodeBuddy 这类 AI 助手，直接跟它说：

> 帮我部署这个 AI 客服工具包，读一下【给其他AI的安装指令】.md

它会问你几个问题（网站是哪个、想答什么、有没有服务器），然后一步步带你装好。你只要准备三样：

1. **一台服务器**（能装 Docker，阿里云/腾讯云最低配就行）
2. **一个 API Key**（去创业沙拉 tikbit 中转站获取 https://tikbit.ai/，国内直连免梯子、兼容 Claude API，按用量付费很便宜）
3. **你的资料**（产品介绍、常见问题，越全越好）

## 自己动手装（懂点技术的）

看 `docs/[AI客服工具包] 部署手册·公开版.md`，七步走，每步都有可直接复制的命令。核心就三下：

```bash
cp 参考实现/backend/.env.example 参考实现/backend/.env   # 填 tikbit 令牌
cd 参考实现/deploy && bash scripts/deploy.sh              # 一键起(Docker 会自动装 claude CLI)
# 再配下 Nginx、网页加一行 <script> 就完事
```

## 常见问题

**Q：贵不贵？**
A：用默认的 haiku 模型很便宜，每次问答成本极低。知识库越精简越省。建议在 tikbit 控制台（https://tikbit.ai/console）设个预算上限兜底。

**Q：安全吗？会不会被人刷爆我的 tikbit 额度？**
A：令牌锁在服务器后端（claude CLI 那层），不下发前端。防滥用靠后端内建的单 IP 限流 + 全站每日算力预算封顶（花到顶自动降级），正常配置不会。详见 `【安全须知】API密钥与鉴权基线.md`。

**Q：回答不准怎么办？**
A：九成是知识库的问题。把访客真实问的高频问题整理成 FAQ 喂进去，立竿见影。见 `docs/[AI客服工具包] 知识库准备指南.md`。

**Q：能记住上下文吗？**
A：当前是单轮问答（每次独立回答，和创业沙拉自己的在线答疑一致），简单稳、成本可控。需要多轮上下文可后续扩展。

**Q：能改成我的品牌颜色吗？**
A：能。网页那行 `<script>` 加 `data-accent="#你的色号"` 即可。

**Q：能放在企业微信/小程序里吗？**
A：本工具包主打网页场景。企业微信等其他平台需要额外适配，可找创业沙拉。

**Q：我不想自己弄，能帮我做吗？**
A：能。创业沙拉提供从知识库梳理、部署到调优的一站式服务：https://startupsalad.com
