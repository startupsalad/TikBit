## 工作流说明

### 使用 html-page skill 时

1. **触发词识别** — Claude 自动识别：
   - "H5落地页"、"推文页"、"活动页"、"HTML宣传页"、"发手机看的页面"

2. **自动加载设计系统** — 根据你选择的风格：
   - 读取对应的 `design-systems/{style}.md` 文件
   - 提取颜色、字体、间距、组件规范

3. **生成移动端优先 HTML** — 遵循规范：
   - 375px 基础宽度（移动端）
   - 所有样式内联（便于 PDF 转换）
   - 响应式布局（逐步适配桌面）
   - 无外部依赖（Google Fonts + inline CSS）

4. **一键转 PDF**（可选） — 调用长图PDF skill：
   - 单页无缝（不会被 A4 分页）
   - 宽度压缩到 760px（手机竖屏舒适）
   - 直接发微信、钉钉、企业微信

## 注意事项

### ✅ 做得好的做法

- 提前告诉 Claude 你需要的风格（clean / luxury / 自定义）
- 列出所有内容：标题、副标题、正文、按钮、二维码等
- 想转 PDF 就说"同时转长图PDF"
- 需要对比多个版本就直接说"帮我分别用 X、Y、Z 三个风格试试"

### ❌ 容易踩坑

- ❌ 说"随便设计一个"（没有风格指向，Claude 会自己选，可能不符合预期）
- ❌ 要求外部图片 CDN（转 PDF 时可能无法加载；优先用内联渐变或 SVG）
- ❌ 要求 `position: fixed`（微信内置浏览器会卡；用普通流式布局）
- ❌ 用 `vw` 单位（转 PDF 时会溢出；用 `px` 或 `%`）
