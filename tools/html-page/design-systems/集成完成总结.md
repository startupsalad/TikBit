## 核心价值

### Before（之前）
- 每次做 HTML 推文页都要从零开始
- 没有统一的风格、客户品牌无法复用
- 生成 → 转 PDF 流程繁琐、需要多步操作

### After（现在）
```
你的提示：
  "帮我做一个某行活动H5，luxury风格，内容是..."

Claude 自动：
  1. 读取 .claude/design-systems/luxury.md
  2. 应用暗色奢华设计规范
  3. 生成单列移动端 HTML（375px）
  4. 提示："需要转长图PDF吗？"
  5. 一键转 PDF（微信、钉钉可用）
```

**节省时间**：从 30 分钟（手工调整样式）→ 3 分钟（调参 + 转 PDF）

## 使用提示

### 何时用 html-page skill
✅ 活动推文页、落地页、宣传页
✅ 需要快速套用风格
✅ 最终要转 PDF 发手机

### 何时用 frontend-design skill
✅ 需要从零创意设计
✅ 要求完全自定义风格
✅ 复杂交互和动效

### 两者可以配合
- 先用 frontend-design 设计独特风格 → 保存为新的 DESIGN.md
- 后续用 html-page 套用这个新风格 + 快速迭代
