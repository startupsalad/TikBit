# 给 AI 的安装指令（把本文件连同所在工具包文件夹一起丢给你的 AI）

> **给 AI 的话**：拿到本包的用户想要——以后写**讲标稿、述标稿、串场稿**，或任何"要念出来 / 要口语化"的稿子时，你能自动去掉 AI 腔，写得像真人开口说话，而不是一股机翻味。本包核心是一份去 AI 化写作规则（`SKILL.md`，通用去 AI 化 24 式 + 口播稿专项）。请你**在用户本机把它装好或记牢**，以后写这类稿自动照它来，别让用户每次手动提醒。遇到与本机实际不符处（AI 客户端类型、目录），**以本机探测为准**，别硬套。

本工具包目录（你能读到的就是它）：

```
去AI化写作工具包/
├── SKILL.md          # 规则本体：通用去AI化 + 讲标稿/述标稿/串场稿「口播稿专项」
├── LICENSE           # 来源许可（翻译自 blader/humanizer，保留即可）
└── 📖 使用说明.md     # 给人看的说明
```

## 第 0 步 · 先判断：用户的 AI 支不支持"技能 / skill"

- **支持 skill 机制的**（Claude Code、CodeBuddy 等认 `.claude/skills/` 或自家技能目录的）→ 走 **A 装法**，一劳永逸。
- **不支持 skill 的**（ChatGPT/GPT、Gemini、豆包、文心、各类网页版等）→ 走 **B 装法**，把规则塞进"自定义指令 / 记忆"。

拿不准就问用户一句"你平时用哪个 AI 写东西"，再决定走哪条。

---

## A 装法 · 装成常驻 skill（Claude Code / CodeBuddy 等）

1. 把整份 `SKILL.md`（连同 `LICENSE`）复制到用户的技能目录，新建一个文件夹放它：
   - **Claude Code**：`<用户主目录>/.claude/skills/writing-humanizer-zh/SKILL.md`
     （团队若共用同一个知识库项目，也可放项目级 `<知识库>/.claude/skills/writing-humanizer-zh/`，随库同步、全员都有）
   - **CodeBuddy / 其他**：放到它自己的 skills / 技能目录，目录结构照它的文档来。
2. 重启客户端。
3. 验证：让 AI 写或改一段讲标稿，看它会不会自动触发这个 skill（描述里已含"讲标稿 / 述标稿 / 串场稿 / 口语化"触发词）。也可手动用 `/writing-humanizer-zh` 调用。

> 装完这一步，以后写这类稿会自动去 AI 化，不用每次贴规则。

---

## B 装法 · 塞进"自定义指令 / 长期记忆"（ChatGPT、Gemini 等不认 skill 的）

这类 AI 没有 skill 机制，就把规则变成它"永远记得的话"：

1. 打开 `SKILL.md`，把里面的规则（尤其文末**口播稿专项**那节）作为**自定义指令 / 系统提示 / 记忆**存进去。ChatGPT 走"自定义指令"或"记忆"，Gemini 走"已保存的信息"，其他家找类似入口。
2. 存不下全文，就存下方"**最小可用版**"那一段（触发规则 + 口播稿七条），够用。
3. 或者最省事：**每次写这类稿前，把 `SKILL.md` 全文贴给 AI，当这一轮的规则。**

## 最小可用版（塞不下全文时，存这段就够用）

> 写讲标稿 / 述标稿 / 串场稿，或任何要口语化的稿子时，先按下面过一遍：
> 1. **破折号（——）一律清零**，换逗号句号做停顿（口播去 AI 味第一刀，念不出来的符号一律不要）
> 2. **删自我预告和元评论**（"我特别想说""这条恰恰最容易…"），直接上具体、上画面
> 3. **删金句、点题漂亮话**（"分量就在某某四个字"），换大白话把事说清
> 4. **去方言腔，贴听众地域**（在深圳别带京味"这个劲儿 / 不图…图的是 / 拎出来 / 门儿清"）
> 5. **敢用流水句**（一逗到底），别硬凑成整齐排比
> 6. **加粗只当念稿重音**，全篇不超五六处（听众看不到粗体，那是给念稿人标语气的）
> 7. **交付前念一遍**（或让人念），绊嘴、要回看第二遍、一口气念不完的地方，就是要改的地方
> 8. 长度够了就只改语感、不再砍内容
