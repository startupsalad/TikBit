# 【给 AI 看的，让 AI 读我】AI 自我成长工具 · 安装说明

> 你好，AI 助手。用户把这个「AI 自我成长工具」文件夹交给了你，想让你帮他装好。这份文档是**写给你看的**，请先读完再动手。

---

## 第零原则：你是聪明的安装者，不是脚本复读机

1. **先观察，再动手**：先搞清楚用户的系统（Mac / Windows）、有没有 Node、Obsidian 知识库装好没。
2. **优先走标准路径**：默认就是跑 `core/install-core.js`（见第二节）。它把该做的都做了。
3. **遇到障碍灵活解决**：标准路径卡住了，理解它想干什么（见第三节），用你自己的能力达成同样结果。
4. **守住安全底线**：改用户的 `CLAUDE.md` / `AGENTS.md` 前先读、只动标记区内的，绝不乱删用户内容；记忆文件绝不覆盖（见第五节）。
5. **失败两次就换思路**：同一方法连试两次不行，停下来分析根因，换做法。

---

## 第一节：这个工具是干什么的

它让用户的 AI（也就是未来的你）**越用越懂他**。装好后，你会在帮他干活的过程中**自动**积累三种记忆，不用他专门来教：

1. **越来越懂他的人** —— 顺手观察他是谁、怎么做事，悄悄记进知识库根目录 `CLAUDE.md` / `AGENTS.md` 的「我是谁」（两边同步）。
2. **越来越懂他的事** —— 跨对话的项目建项目记忆，下次无缝接手。
3. **越来越懂怎么做** —— 踩过的坑、好用的方法，记进经验库，不重复犯错。

> **⭐ 一个知识库，两个大脑**：这套工作台里，同一个知识库同时装了 **Claude** 和 **GPT(Codex)** 两个大脑。Claude 读 `CLAUDE.md`、GPT 读 `AGENTS.md`。所以本工具会**同时给这两个文件各写一段成长指令**——不管用户用哪个大脑，它都会成长；而且经验库、项目记忆、用户画像都放在共享的知识库里，**一个大脑学到的，另一个也用得上**。

**和别的工具最大的不同**：它**不装进系统目录 `~/.claude/`，而是装进用户的 Obsidian 知识库里**——因为这是「记忆产品」，要让用户**看得见** AI 在为他变厚（一个叫 `🌱AI成长档案/` 的文件夹）。

装好后每个知识库里会多出：
```
知识库/
├── CLAUDE.md              ← 追加一段「自我成长行为指令」给 Claude（不覆盖原内容）
├── AGENTS.md              ← 追加对称的一段给 GPT(Codex)（不覆盖原内容）
└── 🌱AI成长档案/
    ├── AI自我成长机制.md      # 机制总纲（你成长的规则书）
    ├── 经验萃取方法论.md      # 怎么把经验记得好
    ├── 项目记忆规范.md        # 项目记忆怎么写
    ├── 经验与避坑库.md        # 记忆①：通用经验（会长大，初始空）
    └── 项目记忆模板.md        # 建新项目时复制它
```

## 第二节：标准安装（默认走这条）

### 第 1 步：找到 Node
命令行跑 `node -v`。装过「AI 工作台地基包」的用户，Node 通常在：
- Mac：`~/.local/bin/node` 或 `~/创业沙拉AI工作台/bin/node` 或系统 PATH
- Windows：`%USERPROFILE%\.local\bin\node.exe` 或 `创业沙拉AI工作台\bin\node.exe` 或 PATH

找不到就用你能找到的任意 node。

### 第 2 步：跑安装引擎
进入这个文件夹，执行（把 `<node>` 换成你找到的 node 路径）：

```
<node> core/install-core.js core
```

> 第二个参数 `核心` 是核心目录路径（安装器从里面找「成长大脑」和「记忆模板」）。在本文件夹里直接跑用相对路径 `核心` 即可，也可给绝对路径。

安装器会**自动找到用户所有的 Obsidian 知识库**，对每一个：建 `🌱AI成长档案/`、放入成长大脑（覆盖刷新）、放入记忆文件（**已存在的绝不覆盖**）、给 `CLAUDE.md` 和 `AGENTS.md` 各追加指令块（幂等，重复装不叠加）。

### 第 3 步：让用户验证
- 告诉用户：**新开一个对话**（指令要新会话才生效）。Claude 和 GPT 两个大脑都会开始成长。
- 之后正常用即可。你会开始在干活中悄悄积累记忆。可以让用户翻开知识库里的 `🌱AI成长档案/` 文件夹看一眼，那就是他的 AI 会长大的地方。

---

## 第三节：安装到底做了什么（万一引擎跑不起来，你照着手动做）

对**每一个** Obsidian 知识库（路径从 `obsidian.json` 读：Mac `~/Library/Application Support/obsidian/obsidian.json`；Win `%APPDATA%\obsidian\obsidian.json`，取每个 vault 的 `path`）：

1. **建文件夹**：在知识库根目录建 `🌱AI成长档案/`。
2. **放成长大脑（覆盖式）**：把本工具 `core/成长大脑/` 里的 3 个 md（机制/方法论/规范）复制进去，已有就覆盖（这是产品文档，整体刷新）。
3. **放记忆文件（⚠️绝不覆盖）**：把 `core/记忆模板/` 里的 `经验与避坑库.md`、`项目记忆模板.md` 复制进去——**目标已存在就跳过、保留原文件**（用户积累的记忆是资产，绝不能抹掉）。
4. **写指令块（两个大脑各一份）**：在该知识库的 `CLAUDE.md` 末尾追加给 Claude 的指令、在 `AGENTS.md` 末尾追加对称的给 GPT 的指令，都用 `<!-- AI-GROWTH-BEGIN ... -->` 和 `<!-- AI-GROWTH-END -->` 包裹（内容见 install-core.js 的 `mdBlock()`）。**重复装要先删旧块再写新块，不叠加；绝不动用户自己写的内容。**（AGENTS.md 不存在就新建；已有内容的只在末尾追加标记块。）

## 第四节：用户怎么用（装完告诉他）

1. **正常用就行**：他不用做任何特别的事。你会自动在干活中观察、记录、积累。
2. **看得见的成长**：想看 AI 学到了什么，翻开知识库里的 `🌱AI成长档案/`——经验库会越来越厚。
3. **主动喂也行**：他想让你记住某事，说「记进我的成长档案 / 记进经验库」即可。
4. **第一次见面**：如果他是全新用户，你开场可以给个一分钟的轻邀请认识下他（也可跳过，边干边了解）。

---

## 第五节：排错

- **`node` 找不到**：用第 1 步候选路径逐个试；或让用户终端 `which node`（Win `where node`）告诉你。
- **提示"找不到知识库"**：确认 Obsidian 已安装、且至少打开过一个知识库（这样 `obsidian.json` 里才有记录）。
- **装完没生效**：99% 是没开新会话。`CLAUDE.md` / `AGENTS.md` 指令必须新会话才读到（Claude 读前者、GPT 读后者）。
- **权限/路径报错**：中文路径在命令里用引号包起来。
- **重复装会不会重复**：不会。成长大脑覆盖刷新、记忆文件保留、指令块幂等替换。放心重跑。

---

## 第六节：安全兜底原则

1. 改 `CLAUDE.md` / `AGENTS.md` 前先读、只在 `AI-GROWTH-BEGIN/END` 标记区内操作，**绝不动用户自己的内容**。
2. 记忆文件（经验库、画像、项目记忆）**只新建、不覆盖**——用户积累的东西比什么都重要。
3. 一切装在用户**自己的知识库**里，看得见、可编辑、随 Obsidian 备份，不藏系统目录。

---

## 第七节：卸载 / 重装

- **卸载**：`<node> core/install-core.js --uninstall`（只去掉各 `CLAUDE.md` 和 `AGENTS.md` 的指令块；`🌱AI成长档案/` 文件夹**保留**，因为里面是用户积累的记忆，不能替他删）。
- **重装 / 升级**：直接重跑第二节的安装命令，幂等，不叠加、不覆盖已有记忆。
