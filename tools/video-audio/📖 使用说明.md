# 视频音频处理工具包 使用说明

> **给人类用户看的说明文档**。如果你是 AI，请看 `给AI的安装指令.md`。

## 这是什么

**视频音频处理工具包**，整合了3个 Agent Skill，处理视频下载、视频理解、本地语音转写三个场景。

| Skill | 功能 | 来源 | 协议 | Star |
|:---|:---|:---|:---|:---|
| **video-catcher** | 下载网络视频（YouTube/Bilibili/抖音/X/TikTok等），支持字幕/封面/清晰度选择/批量 | [Weikezi-AI](https://github.com/Weikezi-AI/video-catcher) | ⚠️ GPL-3.0-only | — |
| **watch** | 读懂一段视频（URL 或本地文件），抽帧+转写后帮你回答问题 | [bradautomates](https://github.com/bradautomates/claude-video) | MIT | — |
| **local-transcribe** | 本地语音/视频转文字，生成 MD 文字稿 + SRT 字幕，不上传，不用 API Key | 创业沙拉 AI 团队 | MIT | — |

## 适用场景

### 1. 下载视频——video-catcher

**适合场景**：需要把网络视频保存到本地

- 下载 B 站/YouTube/抖音/TikTok/X/Instagram 视频
- 指定清晰度（360p/720p/1080p/2K/4K）
- 下载带中文字幕的版本
- 批量下载播放列表
- 断点续传
- 查看一个网页里有哪些视频资源

**触发示例**：
- "帮我下载这个视频 [URL]"
- "把这个 B 站链接保存下来"
- "这个视频有哪些清晰度可以下"
- "下载这些链接的视频，720p 即可"

**使用限制**：
- 只能下载用户有权访问/保存的内容
- 不支持绕过 DRM、付费墙、会员权限
- 下载≠获得版权/转载授权

---

### 2. 理解视频内容——watch

**适合场景**：想让 AI 帮你看一段视频，回答里面说了什么/讲了什么

- "这个视频讲了什么？"
- "视频里提到了什么产品/数据/方案？"
- "帮我总结一下这段教程"
- "视频里2分半钟那段在说什么"
- 对本地视频文件提问

**触发示例**：
- "/watch [视频URL]"
- "/watch [视频URL] 里面说的核心方法是什么"
- "/watch 本地视频.mp4 帮我整理笔记"

**工作方式**：
1. yt-dlp 下载视频（本地文件跳过）
2. ffmpeg 提取关键帧为图片
3. 获取字幕（优先原生字幕，无字幕时调 Whisper API 转写）
4. 结合图片+文字稿，AI 直接回答你的问题

**注意**：watch 使用云端 Whisper API（Groq 或 OpenAI），需要配置 API Key。如果只想本地转写不上云，用 local-transcribe。

---

### 3. 本地语音转文字——local-transcribe

**适合场景**：有本地录音或视频，需要转成文字

- 会议录音转文字稿
- 访谈/播客音频转文字
- 课程/讲座录音转字幕
- 视频生成 SRT 字幕文件
- 不想把录音上传到云端（隐私保护）
- 没有 API Key 或不想消耗 API 额度

**触发示例**：
- "帮我把这段录音转成文字 [文件路径]"
- "给这个视频生成字幕文件 [文件路径]"
- "本地转写，不上传"

**工作方式**：
1. 使用 faster-whisper（本地 Whisper 推理，MIT 协议）
2. 自动检测 GPU（有 GPU 就用，没有或 GPU 库不全就降级 CPU）
3. 生成 `.md` 文字稿 + `.srt` 字幕
4. 全程不联网（模型已缓存后）

**首次使用**：会自动下载 Whisper 模型到本地（medium 约 1.5 GB）。国内网络不通时自动切 hf-mirror.com。

## 怎么分发给同事

### 方法1：发整个文件夹

把 `视频音频处理工具包/` 整个发给同事，让同事：
1. 把 `给AI的安装指令.md` 发给自己的 AI
2. AI 读完后会自动安装（支持 Skill）或提示手动粘贴（不支持 Skill）

### 方法2：只发 zip

在文件夹里找到 `视频音频处理工具包.zip`，直接发给同事。
同事拿到 zip 后告诉 AI："帮我安装这个工具包"，AI 会自动解压安装。

## 常见问题

**Q：watch 和 local-transcribe 有什么区别？**

A：watch 是"让 AI 看懂视频、回答问题"——既抽帧又转写，输出是 AI 的分析回答。local-transcribe 是"单纯转文字"——只做 ASR 转写，输出是文字稿/字幕文件，不做 AI 分析。

两者也可以配合用：先用 local-transcribe 转写得到文字稿，再把文字稿交给 AI 分析。

**Q：能下载视频然后立刻转写吗？**

A：可以。先用 video-catcher 下载视频到本地，再用 local-transcribe 转写，或直接用 watch（watch 内置了 Whisper 调用，但需要 API Key）。

**Q：local-transcribe 速度怎么样？**

A：medium 模型，CPU 模式下大约实时1-4倍速（即1小时录音需15-60分钟），具体取决于 CPU 性能。有可用 GPU 时显著更快。

**Q：视频下载会侵权吗？**

A：技术上可以下载≠拥有版权。下载仅用于合法的个人学习/保存/备份目的。转发、用于商业用途请先确认版权。
