# OfficeCLI 使用说明（给人看的）

## 一句话

让 AI 真正**改得动**已有的 Word / Excel / PPT，而不是只能从零重做一份。

## 它解决什么痛点

以前 AI 改客户给的存量 PPT，只能靠形状序号摸着改，改不准就整份重建 —— 客户的原始版式全丢。
现在 AI 能像查网页一样查文档：「把所有小于 14pt 的文字找出来」→ 拿到每一处的精确位置 → 批量改 → 存盘校验 → 渲染出图自己看一眼对不对。

实测：那份 26 页客户 BP，43 处超小字号一次性定位并修正，963 个元素一个没丢，文件结构校验通过。

## 什么时候该想起它

- 客户发来一份 PPT/Word/Excel，要**在原件上改**（不是重做）
- 要检查一份 PPT 有没有违反「正文≥14pt」这类规范，且要知道**具体哪一页哪个框**
- 要读文档的结构（标题层级、sheet 公式数、页眉页脚域）
- 做标书核查，要处理**修订和批注**
- 要做融资路演 PPT、财务模型、可填写表单（内置对应专业 skill）

## 什么时候别用它

- 读老格式 `.doc/.xls/.ppt/.rtf/.wps` —— 它完全不支持，走 `文档读取编辑工具包/`
- 要转 PDF —— 它导不了，走现有转 PDF 方案
- Markdown 转 Word —— 走 `md2word.py`
- 要审美/版式判断 —— 那是人的活，工具只管执行

## 内置的 10 个专业场景

`word`、`excel`、`pptx` 三个基础，加 7 个专项：

| Skill | 干什么 | 跟我们哪块活对得上 |
|:---|:---|:---|
| `pitch-deck` | 融资路演 PPT（种子轮到 C 轮） | 客户 BP 美化、投资人材料 |
| `financial-model` | 三表模型 / DCF / 敏感性分析 | 项目财务测算 |
| `word-form` | 可填写表单（内容控件+文档保护） | 报名表、送检申请表 |
| `data-dashboard` | Excel 数据看板 + KPI 卡 | 项目统筹推进表升级 |
| `academic-paper` | 论文（引用格式/公式编号/参考文献） | 暂无对应 |
| `morph-ppt` | 跨页平滑动画 PPT | 流程演示 |
| `morph-ppt-3d` | 3D 模型 PPT | 空间/设备展示 |

> ⚠️ 后 7 个只看了触发说明，**没实际出件验过质量**，第一次用要盯着结果。

## 怎么用

装好之后不用记命令 —— **直接跟 AI 说要干什么就行**，skill 会自动触发。
比如「把这份 BP 里所有小于 14pt 的正文找出来给我个清单」。

自己想动手，命令长这样：

```bash
officecli view deck.pptx stats                    # 看概况
# 查字号：必须逗号并集，size 与 effective.size 互斥
officecli query deck.pptx "run[size<14],run[effective.size<14]" --compact --fields size
officecli set deck.pptx '/slide[7]/shape[@id=11]/paragraph[1]/run[1]' --prop size=14
officecli close deck.pptx                         # 存盘释放
officecli validate deck.pptx                      # 校验没坏
officecli view deck.pptx screenshot -o out.png    # 渲染出图看一眼
```

## 五个必须知道的坑

1. **`view issues` 靠不住** —— 对 9.5pt 超标的文件返回「0 issues」，它不认我们的规范。查字号必须显式 query。
2. **`size` 与 `effective.size` 互斥，漏一边就假报「没问题」** —— `size` 只匹配显式设了字号的，`effective.size` 只匹配靠继承的，交集为 0。测试件里前者中 2、后者中 4；真实 BP 里前者 291、后者 0。**一律用并集 `run[size<14],run[effective.size<14]`**。
3. **`set` 不接受裸选择器** —— 批量换文字用 `--find/--replace`，批量改属性得先 `query --json` 取路径再 `batch`。
4. **会占文件锁**（最长 12 分钟）—— 微盘同步盘上别直接开正式交付物，拷到临时目录改完再拷回。
5. **老格式一律不认** —— `.doc/.xls/.ppt` 报 Unsupported，别浪费时间试。

装法和完整限制清单见同目录 `给AI的安装指令.md`。
