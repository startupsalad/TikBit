# 网页设计套件

按品牌与专业方法论制作网站、落地页、官网和 H5，也能诊断并精修已有页面的 AI 模板感。当前版本 0.2.0，支持 Claude 和 GPT／Codex。

## 套件组成

- **设计大脑**：五步法（定调性 → 借骨架 → 写文案 → 执行 → 自检）、品牌定义模板、H5 规范、营销文案经验及 12 个品牌设计参考。
- **web-design-engineer**：设计方向、风格参考与界面实现。
- **frontend-design**：新建前端页面和组件。
- **unslop**：诊断已有页面的间距、颜色、图标、文案、字体、布局、细节、素材与动效，按问题轻重改稿。

## 安装与更新

已支持此功能的 TikBit 工作台：进入 **设置 → 更多工具 → 网页设计套件**，选择安装或更新；完成后在新对话使用。缺文件时按入口提示修复，已有自定义修改须确认保留方式，不强行覆盖。

通过 AI 安装：将本仓库地址交给 AI，明确说“安装或更新网页设计套件”，让它读取本目录 [INSTALL.md](INSTALL.md)。不再依赖旧原始安装包或 install-core.js。未安装工作台可从 https://tikbit.ai/workstation 获取，工具库入口为 https://github.com/startupsalad/TikBit 。

工具文件发布、用户点击更新及新对话实际加载是不同状态。GitHub 源码变更不会自动覆盖用户的本地 Skill，也不会自动同步上海 OSS；需由维护者先发布新版本包和清单，再按工具库流程同步主源。

## 怎么使用

新建页面：“帮我做一个产品落地页，沿用当前品牌，先给结构和设计方向。”

只做诊断：“用 unslop 检查这个页面，先列位置、问题、影响和建议，不修改代码。”

精修改稿：“用 unslop 精修这个本地页面，保留品牌、功能、区块和真实数据，给我电脑和手机前后对比。”

Codex 可用 $unslop，Claude 可用 /unslop；自然语言也可。仅有网址时可以制作本地静态副本，不会直接修改线上网站；有源码时优先改源码。

## 能力边界

- 品牌与现有组件优先，不把所有页面改成同一种风格。轻度局部修，合适的页面不强行重做。
- 不编造业务数据或宣传数字，不擅改登录、表单、路由及功能。
- 不自动生图、录视频或上线。模型用量及用户明确选择的素材生成依各自服务计费，Skill 安装不含这些费用。
- 诊断与改稿复用宿主能力；可选快照脚本需要 Node.js、Playwright 和浏览器，录制另需 ffmpeg，依赖按任务准备。Skill 安装成功不等于这些依赖已准备。
- 深色快照可能改变浏览器原生控件颜色，脚本交互和部分跨域资源可能无法保存，需对照原页检查。

具体执行边界见所安装 unslop Skill 的 references/usage-boundaries.md。快速套用落地页仍可用 html-page，本套件补充设计方法与精修。
