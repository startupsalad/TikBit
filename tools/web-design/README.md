# 网页设计套件

一套让 AI 按专业方法论设计网站/落地页/官网/H5 的"设计大脑"，避免"AI 模板货"感，产出更高级的设计。

## 📦 套件组成

### 1. 设计大脑（`设计大脑/`）

核心方法论和参考资源：

- **网页设计方法论.md** — 总纲，五步法（定调性 → 借骨架 → 写文案 → 执行 → 自检）
- **定义你的品牌.DESIGN.md** — 空白品牌模板，引导定义自己的视觉语言
- **设计语言参考库/** — 12 个世界级品牌官网逆向的 DESIGN.md：
  - Stripe, Linear, Vercel, Apple, Notion, Framer, Figma, Raycast, Cal, Nike, Spotify, Airbnb
- **网站撰写经验.md** — 营销文案实战经验
- **H5页面设计规范.md** — H5 规范和现成代码模板

### 2. 执行技能（`skills/`）

- `web-design-engineer/` — 包含大量设计风格参考（style-recipes/）
- `frontend-design/` — 前端设计执行能力

## 🚀 快速开始

### 使用方式

直接告诉 AI：

```
帮我做一个产品落地页，Linear 那种极简感。
```

AI 会自动：
1. 读取 `网页设计方法论.md`
2. 从参考库中挑选 Linear 的 DESIGN.md 作为调性骨架
3. 按五步法设计和执行

### 定义品牌（推荐）

```
帮我定义品牌设计语言
```

AI 会打开 `定义你的品牌.DESIGN.md`，引导你填写品牌色、字体、调性，建立统一视觉体系。

## 📋 安装到个人环境

**注意**：这个工具包在团队工具库里是"源文件"，个人使用需要安装到本机 `~/.claude/` 目录。

### 安装步骤

1. 把本工具包文件夹路径告诉你的 AI
2. 让 AI 读取桌面原始安装包里的 `【给AI看的，让AI读我】安装说明.md`
3. AI 会自动复制文件到：
   - `~/.claude/web-design/` — 设计大脑
   - `~/.claude/skills/` — 执行技能（如果不存在）
   - 并在 `CLAUDE.md` 中添加使用指令

### 快速安装命令

如果有 Node.js，可以直接运行（需要原始安装包的 `install-core.js`）：

```bash
node <原始安装包>/核心/install-core.js <原始安装包>/核心
```

## 📝 与其他工具的关系

### vs HTML页面生成系统

- **HTML页面生成系统**：10 套预制风格，快速套用，重点是效率
- **网页设计套件**：从零创意设计，详细的设计思考，重点是质量

→ 可以配合使用：快速原型用 HTML 系统，精品设计用设计套件

### vs frontend-design skill

- **frontend-design skill**：是设计套件的"执行技能"之一
- 设计套件提供方法论和参考库，frontend-design 负责实际编码
