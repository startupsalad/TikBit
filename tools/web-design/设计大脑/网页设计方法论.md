# 网页设计方法论 · 一份让 AI 做出"更好看的网站"的总纲

> **给 AI 的话**：这份文档是你做网页设计时的「总指挥」。任何时候用户让你做网站、落地页、官网、产品页、活动页、H5——**先读完这份，再动手**。
>
> 它不是又一份"写代码的教程"，而是教你**怎么思考一个设计**：先定调性，再借骨架，再写文案，再执行，最后自检。少了"思考"这一层，AI 默认产出的就是那种"能跑但很平庸、一眼假"的网页（业内叫 AI slop）。这份文档存在的唯一目的，就是让你的产出**明显比不用它的时候更好看、更高级、更可信**。

---

## 0. 一句话心法

> **顶级设计 = 一个清晰的方向 × 精心的执行细节。**

平庸的网页不是"做得不对"，而是"没有方向"——什么都想要，于是什么都不突出；用最安全的默认值（紫粉渐变、Inter 字体、居中堆叠的卡片），于是和满世界的 AI 网页长得一模一样。

你要做的第一件事，永远是**先选定一个大胆、明确的方向**，再用工匠级的细节把它执行到位。宁可"极简到极致"或"繁复到极致"，也不要落在没有记忆点的中间地带。

---

## 1. 五步法（拿到需求后照着走）

```
① 定调性    →  ② 借骨架    →  ③ 写文案    →  ④ 执行    →  ⑤ 自检
   这是什么页      挑1个参考       内容先行       搭页面        过质量清单
   给谁看          品牌当地基      不是占位符      接动效        防 AI slop
   什么气质
```

每一步都不要跳。跳过①②直接写代码 = 平庸的根源。

---

## 2. 第①步：定调性（30 秒，但决定一切）

动手前，先在心里（或跟用户确认）回答三个问题：

1. **这是什么页？** 官网首页 / 产品落地页 / 转化页 / 活动 H5 / 作品集 / 文档站——不同类型有不同的首屏逻辑和信息密度。
2. **给谁看？** 企业老板 / 开发者 / 年轻消费者 / 投资人。受众决定语气（务实严谨 vs 活泼前卫）和视觉密度。
3. **要什么气质？** 用 2-3 个形容词钉死方向：比如「专业 · 克制 · 高级」或「活力 · 大胆 · 年轻」或「温暖 · 人情味 · 易读」。

> ⚠️ 如果用户没说清，**主动用一句话提议一个方向**（"我建议走 Linear 那种极简精密的工程师调性，你看行吗？"），别自己闷头猜，也别给一个谁都不得罪的平庸默认值。

---

## 3. 第②步：借骨架（核心动作 · 用好参考库）

本套件自带一个 **设计语言参考库**（`设计语言参考库/` 目录），里面有 12 个世界级品牌官网逆向出来的 `DESIGN.md`（Stripe / Linear / Vercel / Apple / Notion / Framer / Figma / Raycast / Cal / Nike / Spotify / Airbnb）。每份都拆好了：色板、字体层级、组件样式、布局间距、阴影深度、Do's & Don'ts、响应式断点。

**怎么用（三条铁律）**：

1. **挑 1 个，不要混搭**。按第①步定的气质，从 `设计语言参考库/索引.md` 里挑一个调性最接近的品牌，**只用它**当这次设计的地基。混搭两三个品牌 = 必乱。
2. **借结构，不照搬配色**。参考库给你的价值是：字体层级怎么拉对比、间距节奏怎么递进、组件手感（按钮/卡片/导航）怎么做、留白哲学。**配色你要换成项目自己的品牌色**（见第④步和 `定义你的品牌.DESIGN.md`），不要直接把 Stripe 的靛紫、Spotify 的绿照抄过去。
3. **先读品牌，再读参考**。如果这个项目已经定义了自己的品牌（填好了 `定义你的品牌.DESIGN.md`），先读它锁定配色和字体，再用参考库补"调性骨架"。参考库是"灵感来源"，不是"标准答案"。

**挑选速查**（详见索引）：

| 想要的感觉 | 挑这个参考 |
|---|---|
| 专业 / 高级 / 企业级落地页 | stripe、linear |
| 极致黑白 / 技术感 / 开发者向 | vercel、cal |
| 温暖 / 易读 / 知识课程 | notion、airbnb |
| 动效驱动 / 前卫 / 活动 H5 | framer、figma |
| 暗色高级 / 金属质感 hero | raycast、apple |
| 力量感 / 口号式 / 海报封面 | nike、spotify |

## 4. 第③步：写文案（内容先行，绝不用占位符）

**最毁质感的事，是用 "Lorem ipsum" 或 "标题文字" 这种占位符搭页面。** 真实文案的长度、语气、信息层级，直接决定排版长什么样。先把真内容写出来，再排版。

营销型网页文案的核心原则（做官网/落地页/转化页必读）：

- **首屏 5 秒定生死**：不滚动就看到的部分，必须让人立刻明白「这是什么 + 最核心的 1-2 个卖点」。服务名要够明显，别缩在角落。
- **讲价值，不堆形容词**：每条卖点落到"解决什么实际问题/带来什么结果"，而不是"操作动作"或空洞口号。数字要可信不夸张。
- **真实案例 > 空话承诺**：用"具体场景 + 具体数字"，不空谈"行业领先""效果显著"。
- **体系感（一组并列内容要"同构"）**：多个并列板块的命名格式、排版结构、文字长度都统一，让人感觉是"一个体系下的 N 个子项"，而不是零散堆砌。控制在 4-6 个。
- **CTA 路径清晰**：按钮跳到真正的转化入口；一屏只给一个主 CTA；转化步骤按"低门槛→高承诺"排（先免费聊→再深入）。

> 更细的网页文案与视觉经验，见同目录 `网站撰写经验.md`。

## 5. 第④步：执行（把方向落到像素 · 调用你的"手"）

调性、骨架、文案都有了，现在动手搭页面。本工作台已预装两个执行 skill 作为你的"手"：

- **`web-design-engineer`**：做网页/原型/仪表盘/数据可视化的工程技能，自带 26 个风格配方。
- **`frontend-design`**：高质量前端界面的美学准则，专门对抗"AI slop"审美。

做网页时**主动调用这两个 skill 的能力**。下面是它们共同强调、且最能拉开差距的执行细节：

### 5.1 排版（最容易出"高级感"也最容易翻车的地方）
- **字体**：避开烂大街的 Inter / Roboto 默认。标题用有性格的展示字体拉对比，正文用干净易读的无衬线，数字/标签可用等宽字体。
- **字号节奏要统一**：同一区块内，多行大标题**每行字号必须一致**（一大一小是"显得歪/乱"的头号原因）。标题尽量控制在一行，副标题适当收窄宽度让换行自然。
- **对比要够狠**：标题和正文的字号/字重差距要拉开，别都是中庸的 16px/18px。大胆用很大的标题 + 很小的辅助文字。

### 5.2 色彩（克制是高级感的来源）
- **主色只做强调**，不要大面积铺满——大面积纯色不高端。底色用白/浅色/深黑，主色只点在标题、按钮、徽标、关键数据上，让它"跳出来"。
- 用项目自己的品牌色（`定义你的品牌.DESIGN.md`），不是参考品牌的色。
- 一组并列卡片可各配一个专属辅助色区分维度，但整体仍统一在一套色系里。

### 5.3 空间与留白
- **留白优先**：宁可空，不要挤。留白是高级感最便宜的来源。
- **一屏一主张**：每屏聚焦一个信息 + 一个动作，不堆砌。
- 间距要有节奏地递进（用 4/8 的倍数体系），别忽大忽小。

### 5.4 动效与背景细节（点睛，但点到为止）
- 动效做"若隐若现"的氛围感：滚动渐入（opacity + translateY）、hover 微浮、CTA 呼吸。**多个元素错开延迟**，别整齐划一地同步（呆板）。
- 背景可以加细节（极轻的网格/噪点/光晕），但透明度峰值压低，是背景不是主角。
- 动效必须**可降级**：移动端和 `prefers-reduced-motion` 下关掉最贵的效果（见 5.5）。

### 5.5 移动端优先（大部分人用手机看）
- 排版用响应式类确保手机端自动堆成单列；触控目标 ≥ 44px。
- **SVG 滤镜动画（feTurbulence 湍流等）在手机上是 CPU 杀手**、是卡顿主因——手机端关掉，只保留 CSS 的 opacity/transform 动效（GPU 合成、很轻）。
- 改完任何页面，**都要想一遍手机端长什么样**。

> H5/活动页有一套更具体的毛玻璃 + 渐变 + 滚动动画规范和现成代码模板，见同目录 `H5页面设计规范.md`。

## 6. 第⑤步：自检（交付前过这张"反 AI slop"清单）

做完别急着交。逐条过一遍，命中任何一条"❌"就回去改：

**方向感**
- [ ] 这个页面有没有一个**说得出口的明确气质**？还是"什么都有点、什么都不突出"？
- [ ] 把 logo 和文字遮住，光看视觉，能不能和满世界的 AI 模板网页区分开？

**排版**
- [ ] 用的是不是 Inter/Roboto 这种烂大街默认字体？（是 → 换）
- [ ] 标题和正文的对比够不够狠？还是都挤在中庸字号？
- [ ] 多行标题的字号一致吗？间距节奏统一吗？

**色彩**
- [ ] 主色是不是被大面积铺满了？（是 → 收回来只做强调）
- [ ] 是不是又用了那个紫粉渐变？（是 → 换成项目品牌色）
- [ ] 配色是项目自己的品牌色，还是照抄了参考品牌的色？

**空间**
- [ ] 留白够不够？还是挤成一团？
- [ ] 每屏是不是只讲一件事？

**细节与可信度**
- [ ] 文案是真内容还是占位符？数字可信吗？
- [ ] 首屏 5 秒能不能 get 到"是什么 + 核心卖点"？
- [ ] 有没有 hover/渐入这些让页面"活起来"的微交互？

**移动端**
- [ ] 手机上会不会塌成丑陋的单列、文字溢出、按钮太小？
- [ ] 重的滤镜动画在手机端降级了吗？

**技术正确**
- [ ] （React 项目）`npx tsc --noEmit` 过了吗？清掉没用的 import 了吗？
- [ ] 图片有 alt 吗？颜色对比度够 WCAG 吗？

---

## 7. 速记口诀

> **定方向 → 借骨架 → 真文案 → 抠细节 → 过清单。**
> 主色只点睛，留白要舍得，字体有性格，手机要先想，占位符是大忌。

做到这些，你产出的网站就会跳出"AI 默认款"，进入"有人精心设计过"的那一档。
