# H5页面设计规范

> 适用场景：课程宣传页、活动介绍页、产品落地页等需要精美设计的H5页面。
> 技术方案：现代Web设计风格（Glassmorphism毛玻璃 + 渐变色 + 动态背景 + 滚动动画），单HTML文件包含所有资源。

---

## 设计风格

### 1. 双主题系统（深色/浅色）

- 使用CSS变量（`:root`）定义颜色系统，通过 `[data-theme="dark"]` 和 `[data-theme="light"]` 切换
- 深色主题：深蓝黑背景（#0B0F1A）+ 毛玻璃卡片 + 低透明度光球
- 浅色主题：浅蓝白背景（#FAFBFF）+ 高透明度卡片 + 更低透明度光球
- 主题切换按钮：右上角固定，圆球滑动动画，带月亮/太阳图标

### 2. 渐变色系统

- 三色渐变：天空蓝（#0EA5E9）+ 皇家紫（#8B5CF6）+ 珊瑚玫瑰（#F43F5E）
- 应用场景：标题文字、按钮、分隔线、卡片左边框、数字徽章
- 渐变方向：135度对角线（`linear-gradient(135deg, ...)`）或90度横向

### 3. 毛玻璃效果（Glassmorphism）

- 核心CSS：`backdrop-filter: blur(16px)` + 半透明背景 + 边框
- 卡片hover效果：背景变亮 + 发光阴影 + 轻微上浮（`translateY(-2px)`）
- 适用于：卡片、按钮、标签、主题切换器

### 4. 背景动态光球

- 三个大尺寸圆形（300-400px），高斯模糊（`blur(80px)`），低透明度
- 位置：左上、右中、左下，通过动画缓慢移动和缩放
- 动画：20秒循环，`ease-in-out`，三个光球错开延迟（0s, -7s, -14s）

## 排版风格

### 1. 响应式布局

- 容器最大宽度：780px，居中，左右padding 24px（移动端16px）
- 字号使用 `clamp()`：`clamp(最小值, 理想值vw, 最大值)`，自动适配屏幕
- 网格布局：桌面端2列（`grid-template-columns: 1fr 1fr`），移动端1列

### 2. 板块结构

- 每个板块：45px上下padding，交替使用普通背景和浅色背景（`.alt`）
- 板块标题：居中，带渐变色分隔线（60px宽，3px高，渐变色）
- 板块间距：通过 `section` 的padding控制，避免手动加margin

### 3. 卡片设计

- 基础卡片（`.gc`）：毛玻璃背景 + 圆角16px + 内边距28px + 阴影
- 分类卡片（`.part-card`）：左侧3px彩色边框，不同板块不同颜色
- 网格卡片（`.benefits-grid`）：2列布局，顶部3px渐变条，hover时显示

### 4. 滚动显示动画（Scroll Reveal）

- 初始状态：`opacity: 0` + `translateY(30px)`
- 进入视口后：`opacity: 1` + `translateY(0)`，过渡时间0.7s
- 同一板块内的多个元素可设置不同的 `transition-delay`，形成依次出现效果

## 技术实现

### 1. 结构化标记（必须遵守）

> **目的**：方便后续局部修改，避免每次修改都要全文读取大文件，节约 Token。

**强制要求**：
- 所有 H5 页面必须在关键 section 前加注释标记
- 注释格式：`<!-- Section名称 Section -->`
- 标记位置：紧贴在对应 `<section>` 标签之前

**标准结构示例**：
```html
<!-- Hero Section -->
<section class="hero">
  <!-- Hero 内容 -->
</section>

<!-- Features Section -->
<section class="features">
  <!-- Features 内容 -->
</section>

<!-- Benefits Section -->
<section class="benefits">
  <!-- Benefits 内容 -->
</section>

<!-- Pricing Section -->
<section class="pricing">
  <!-- Pricing 内容 -->
</section>

<!-- CTA Section -->
<section class="cta">
  <!-- CTA 内容 -->
</section>

<!-- Footer -->
<footer>
  <!-- Footer 内容 -->
</footer>
```

**修改流程**（Claude 必须遵守）：
1. 先用 `Grep` 搜索注释标记定位目标 section（例如：`Grep pattern="<!-- Pricing Section -->" file_path="xxx.html"`）
2. 再用 `Read` 指定 offset + limit 读取局部（目标行 ± 50 行）
3. 最后用 `Edit` 精确替换
4. ❌ 禁止：直接 `Read` 全文

**常见 Section 命名**：
- Hero Section（首屏大图/标题）
- Features Section（功能特性）
- Benefits Section（核心价值）
- Process Section（流程步骤）
- Pricing Section（价格方案）
- Testimonials Section（用户评价）
- FAQ Section（常见问题）
- CTA Section（行动号召）
- Footer（页脚）

---

### 2. 单文件自包含

- 所有图片（LOGO、讲师照片、二维码）使用base64编码内嵌
- 优点：无外部依赖，单文件可独立运行，方便分享和部署
- 缺点：文件体积较大（455KB），但对于H5页面可接受

### 3. JavaScript功能

- 主题切换：监听按钮点击，切换 `data-theme` 属性，localStorage持久化
- 滚动显示：`IntersectionObserver` 监听元素进入视口，添加 `.visible` 类
- 价格数字动画：从0滚动到999，使用 `requestAnimationFrame` 实现平滑计数
- 图片加载：动态设置base64 src，避免HTML中直接写超长字符串

### 4. 性能优化

- CSS变量集中管理，减少重复代码
- 动画使用 `transform` 和 `opacity`，触发GPU加速
- 滚动监听使用 `IntersectionObserver`，性能优于传统 `scroll` 事件
- 图片懒加载：通过JS动态设置src，避免首屏加载所有图片

## 经验总结

### 1. 移动端适配

- 必须设置 `<meta name="viewport" content="width=device-width, initial-scale=1.0">`
- 字号、间距、网格列数都要有移动端断点（`@media(max-width:640px)`）
- 触摸目标至少44×44px，避免按钮太小难以点击
- 测试时用真机或浏览器开发者工具的设备模拟器

### 2. 浏览器兼容性

- `backdrop-filter` 需要加 `-webkit-` 前缀（Safari）
- `background-clip: text` 需要加 `-webkit-` 前缀（文字渐变色）
- 避免使用过新的CSS特性（如 `:has()`），除非确认目标用户的浏览器支持

### 3. 可访问性

- 图片必须有 `alt` 属性
- 颜色对比度符合WCAG标准（深色主题尤其要注意）
- 主题切换按钮要有明确的视觉反馈
- 避免纯色彩传达信息（如"红色=错误"），要配合文字或图标

### 4. 内容与样式分离

- 板块顺序、文案内容应该易于修改，不要深度耦合在CSS中
- 颜色、字号、间距等设计参数用CSS变量统一管理
- 如果需要生成多个类似页面，考虑用模板引擎或组件化

### 5. 流程图/生产线可视化设计（2026-03-18新增）

**设计原则**：
- 每个步骤大小一致，保持视觉平衡
- 每个步骤内容量一致（都有标题行+说明行），避免大小不一显得凌乱
- 用 `STEP 1`、`STEP 2` 等标签增强顺序感
- 用emoji增加活力，每个步骤配一个代表性emoji

**配色方案**：
- 5个步骤用5种协调的渐变色，从冷色到暖色过渡
- 推荐色系：天空蓝 `#0EA5E9` → 青色 `#06B6D4` → 紫色 `#8B5CF6` → 粉色 `#EC4899` → 玫瑰红 `#F43F5E`
- 每个步骤：左侧 `border-left:3px solid 对应颜色` + 背景 `linear-gradient(135deg, rgba(颜色,0.12), rgba(颜色,0.04))`

**连接线实现**：
- 步骤之间用 `div` 实现渐变连接线：`width:3px; height:14px; margin-left:24px; background:linear-gradient(to bottom, 上色, 下色)`
- 不要用SVG连接线（viewBox高度难以自适应内容高度，容易变形歪斜）
- 不要用 `border-image` 渐变（兼容性差，且会导致内容不居中）
- 不要用箭头符号 `↓`（视觉效果差）

**居中问题**：
- 外层容器不要加 `padding-left` 或 `border-left`，否则内容会偏右
- 用 `max-width` + `margin: auto` 居中即可

**闭环设计**：
- 如果流程有闭环（最后一步反馈到第一步），在底部加一行小字提示，如 `🔄 数据反哺选题，形成闭环，持续进化`

**踩坑记录**：
- Write工具创建HTML文件可能出现中文编码问题（乱码），应使用Read+Edit方式修改现有HTML文件
- 用Edit工具逐步修改比整体替换更安全，避免编码问题

### 6. 步骤标签徽章设计（Step Badge Tags）（2026-03-23新增）

> 适用场景：课程内容板块中展示多个步骤（如"5步搭建生产线"），每个步骤需要标题+详情列表的布局。与流程图（第5节）的区别：流程图强调步骤间的连接和流向，标签徽章强调每个步骤的内容展开。

**设计模式**：
- 每个步骤用一个**药丸形彩色徽章**作为标题（如 `STEP 1：安装AI`）
- 徽章下方是bullet list展开说明
- 整体放在毛玻璃卡片内，卡片之间有间距

**徽章样式**：
- 形状：药丸形（`border-radius: 20px`），`display: inline-block`
- 背景：对应颜色的低透明度（`rgba(颜色, 0.15)`）
- 文字：对应颜色的高亮度值，`font-weight: 600`，`font-size: 0.85rem`
- 内边距：`padding: 4px 14px`

**渐进配色方案**（5步）：
- STEP 1：绿色 `#10B981`（背景 `rgba(16,185,129,0.15)`）
- STEP 2：青色 `#06B6D4`（背景 `rgba(6,182,212,0.15)`）
- STEP 3：橙色 `#F59E0B`（背景 `rgba(245,158,11,0.15)`）
- STEP 4：粉紫 `#EC4899`（背景 `rgba(236,72,153,0.15)`）
- STEP 5：玫瑰红 `#F43F5E`（背景 `rgba(244,63,94,0.15)`）

**布局结构**：
```html
<div class="fw-card">  <!-- 毛玻璃卡片 -->
  <span class="fw-tag" style="background:rgba(16,185,129,0.15);color:#10B981">
    STEP 1：安装AI
  </span>
  <ul>
    <li>说明文字1</li>
    <li>说明文字2</li>
  </ul>
</div>
```

**与流程图的选择**：
- 需要展示步骤间的流向和连接 → 用流程图（第5节，左侧彩色边框+连接线）
- 需要展开每个步骤的详细内容 → 用标签徽章（本节，药丸标签+bullet list）
- 两者可以在同一页面共存：流程图做总览，标签徽章做详情展开

**嵌套卡片布局**：
- 外层：板块卡片（`.part-card`），包含板块标题（如"Part 2：搭建你的内容生产线"）
- 内层：步骤卡片（`.fw-card`），每个步骤一张，包含徽章+内容
- 内层卡片之间间距 `16px`，与外层卡片内边距 `24px`

### 滚动显示动画 JavaScript

```javascript
// 滚动显示动画
const observer = new IntersectionObserver((entries) => {
  entries.forEach(entry => {
    if (entry.isIntersecting) {
      entry.target.classList.add('visible');
    }
  });
}, { threshold: 0.1 });

document.querySelectorAll('.reveal').forEach(el => observer.observe(el));
```

## 经验总结（2026-04-14新增）

### CSS选择器与样式覆盖

**nth-child 陷阱**：
- `nth-child` 计算的是父元素的**所有子元素**，不是同类元素
- section 里有标题div、卡片div、段落p混排时，`.card:nth-child(1)` 不一定命中第一张卡片
- ❌ 用 `.pain-card:nth-child(1)` 给第一张痛点卡片上色（实际命中的可能是标题div）
- ✅ 直接用内联 `style="border-color:#0EA5E9;background:rgba(14,165,233,0.15)"` 写在每个卡片上

**毛玻璃 .gc 类覆盖问题**：
- `.gc` 的 `backdrop-filter` + `background` 优先级高，会覆盖 CSS 中设置的自定义背景色
- 解决方案：在 HTML 元素上用内联 `style="background:rgba(...) !important"` 强制覆盖

### 全宽背景与居中内容

**问题**：`section{max-width:680px;margin:auto}` 会导致桌面端两侧出现颜色断层——section的背景色只覆盖680px，两侧露出页面底色。

**正确做法**：
```css
/* section 全宽，背景铺满 */
section{padding:32px 16px}
/* 子元素居中限宽 */
section>*{max-width:680px;margin-left:auto;margin-right:auto}
```

**原理**：section 不设 max-width（默认全宽），背景色自然铺满整个屏幕。内容通过 `section>*` 选择器限制在680px并居中。

### 图片引用方式

**不用 base64，用相对路径**：
- ❌ base64：消耗大量 token，文件体积大，修改困难
- ✅ 相对路径：`<img src="蛋总.png">`，图片和 HTML 放同一文件夹
- 优点：省 token、文件小、方便换图、可以直接预览

### 质感提升五件套

以下5个微交互效果可以明显提升H5页面的高级感，且代码量小：

| 效果 | 实现方式 | 作用 |
|------|---------|------|
| CTA按钮呼吸动画 | `@keyframes ctaPulse` box-shadow 脉动 | 吸引点击 |
| 价格数字滚动 | `requestAnimationFrame` 从0滚到目标数字 | 冲击力 |
| 卡片微光扫过 | `::after` 伪元素 + hover时 `left` 位移 | 游戏质感 |
| 顶部滚动进度条 | fixed定位 + scroll事件更新width | 阅读进度感知 |
| 滚动淡入动画 | `IntersectionObserver` + opacity/transform | 层次感 |

// 价格数字滚动动画
const priceEl = document.getElementById('priceAnim');
const target = 999;
let start = null;
priceEl.textContent = '0';

function step(timestamp) {
  if (!start) start = timestamp;
  const progress = Math.min((timestamp - start) / 1200, 1);
  const easeOut = 1 - Math.pow(1 - progress, 3);
  priceEl.textContent = Math.floor(easeOut * target);
  if (progress < 1) requestAnimationFrame(step);
}
setTimeout(() => requestAnimationFrame(step), 600);

// 滚动进度条
window.addEventListener('scroll', function() {
  const bar = document.getElementById('scrollProgress');
  const h = document.documentElement;
  const percent = (h.scrollTop / (h.scrollHeight - h.clientHeight)) * 100;
  bar.style.width = percent + '%';
}, {passive: true});
