# 设计语言参考库·索引

> **来源**：[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md)（开源，MIT），把知名品牌官网的视觉系统逆向提取成 AI 能直接读懂的 `DESIGN.md`。

---

## 一、这是什么 / 怎么用

**DESIGN.md** 是 Google Stitch 提出的概念：一份纯文本的设计系统文档，AI Agent 读了就能生成视觉一致的 UI。一个 markdown 文件，不需要 Figma 导出、不需要 JSON、不需要工具链。

**怎么用（三步）**：
1. 从 `品牌DESIGN库/` 里挑一个调性接近的品牌 DESIGN.md
2. 丢给 AI（你的 Claude / Cursor / Stitch），说"照这个设计语言做页面"
3. **把里面的色值换成你自己的品牌色**（见下方"⚠️ 使用铁律"），保持视觉调性、不照搬配色

**每个 DESIGN.md 含 9 段**：① 视觉主题氛围 ② 色板+角色 ③ 字体层级表 ④ 组件样式(按钮/卡片/输入/导航+状态) ⑤ 布局间距网格 ⑥ 深度阴影 ⑦ Do's & Don'ts ⑧ 响应式断点 ⑨ Agent Prompt 速查。

---

## 二、⚠️ 使用铁律（务必遵守）

1. **不照搬配色**：你应该有自己的品牌系统（在 `定义你的品牌.DESIGN.md` 里定义）。这些参考文件用来借**结构、字体层级、间距节奏、组件手感、留白哲学**，配色一律换成你自己的品牌色。
2. **先读品牌、再读参考**：做任何对外页面前，先读 `定义你的品牌.DESIGN.md` 锁定配色和字体，参考库是"调性灵感"不是"标准答案"。
3. **挑 1 个，不要混搭**：一个页面只参考一个品牌的设计语言，混搭会乱。

## 四、扩充方式（需要别的品牌时）

原库共 73 个品牌（含 Coinbase、Supabase、Tesla、Shopify、Uber 等）。补一个的命令：

```bash
cd "品牌DESIGN库"
base="https://raw.githubusercontent.com/VoltAgent/awesome-design-md/main/design-md"
curl -sfL "$base/<品牌名>/DESIGN.md" -o "<品牌名>.DESIGN.md"
# 品牌名见仓库 README，如 coinbase / supabase / tesla / shopify / uber ...
```

全部品牌清单见原仓库 README：https://github.com/VoltAgent/awesome-design-md
