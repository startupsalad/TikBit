# 📖 对话长度提醒工具包 · 使用说明

## 这是什么

一个 Claude Code 钩子，**对话变长时自动提醒你压缩上下文（/compact）或开新对话，帮你省 token**。

为什么需要它：长对话最烧钱的不是"干活"，而是**每说一句话都要把前面全部聊天历史重读一遍**（按全价计费）。一个对话开到几百轮、挂十几个小时，账单大头全在"反复重读"上——哪怕你只回了个"嗯"。靠 AI 自己记得提醒不靠谱（对话越长它越想不起来），所以用这个钩子在外面兜底。

## 怎么装

- **让 AI 装**：把 `给AI的安装指令.md` 连同整个工具包文件夹发给你的 AI，让它自动装好并测试。本机有 Python 3.6+ 即可。
- 装完**重启 Claude Code** 才生效。

## 装了之后会怎样

对话上下文涨到阈值时，AI 会**先判断你是不是还在聊同一件事**，再自然地提醒你一句——同一件事只是聊长了，优先建议 `/compact` 压缩（保留记忆、挤掉冗余、省 token，不用重新探索）；换了新话题才建议开新对话。三档提醒：

| 上下文规模 | 提醒力度 |
|:---:|:---|
| 约 130K token | 轻提醒：对话有点长了，留意一下 |
| 约 230K token | 建议：同一件事就 `/compact` 压缩，换了话题再开新对话 |
| 约 350K token | 强烈建议：很烧钱了，同一件事赶紧 `/compact`，换话题就存好结论开新对话 |

同一档位只提醒一次，不刷屏。`/clear` 或 `/compact` 之后上下文回落，提醒自动重置。

## 配合习惯，效果最好

- **同一件事聊长了先 `/compact` 压缩**（保住记忆、只挤冗余），一个任务真做完了、或换了新话题再开新对话，别让一个对话挂一整天。
- **读大文件、整份招标文件这类重活，单独开对话做**，别拖着全文在长对话里继续聊。
- 看到提醒别硬扛——存好当前结论，新对话里贴个一句话背景就能接着干。

## 想调阈值

改 `~/.context-reminder/context_reminder.py` 顶部的 `BANDS`（三个数字，单位 token），存盘即生效（下次发消息就按新阈值）。觉得太唠叨就调大，想更早提醒就调小。

## 卸载

删掉 `~/.context-reminder/` 文件夹，再把 `~/.claude/settings.json` 里 `UserPromptSubmit` 下含 `context_reminder` 的那段删掉，重启 Claude Code。
