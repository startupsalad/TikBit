# 📖 AI 营销工具包 · 使用说明

## 这是什么

10 个营销 Skill（Markdown 格式），装进 AI 的技能目录后，写文案、审落地页转化率、做 SEO、定价、产品发布、竞品对比、社媒内容这些营销活，AI 会自动套专业框架来做，不是裸问裸答。

源自开源仓库 [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)（GitHub 40K+ star），作者 Corey Haines 是 Conversion Factory 创始人、营销周刊 Swipe Files 作者，把他多年 B2B SaaS 营销经验拆成了 AI 能直接用的框架。MIT 协议，免费。

原仓库共 46 个 skill，我们按公司业务模式（不做在线自助订阅产品、不跑海外广投放）挑了跟我们相关的 **10 个**装进来：

| Skill | 干什么 |
|:---|:---|
| **product-marketing** | 产品档案（定位/用户/竞品/品牌调性），其余 9 个都先读它——**最先装、最先用** |
| copywriting | 首页/落地页/定价页文案，PAS·AIDA 框架出多版本 |
| copy-editing | 逐段改现有文案，每处改动给理由（不是推倒重写） |
| cro | 审营销页面/表单，按优先级列修改清单 |
| ai-seo | 优化内容让 ChatGPT/Perplexity/Gemini 愿意引用 |
| competitors | 生成竞品对比页 |
| marketing-ideas | 140 个营销点子，卡壳时翻一翻 |
| pricing | 定价和套餐设计 |
| launch | 产品发布节奏安排 |
| social | 社媒内容（默认 LinkedIn/Twitter 打法，国内场景需自己改） |

没装的 36 个里，比较典型的是 SaaS 自助订阅漏斗类（signup/onboarding/popups/paywalls/churn-prevention）和海外投放/销售流程类（ads/ab-testing/revops/cold-email），跟我们业务模式不搭，暂时没装。要装可以去 `skills/` 目录参照下面"怎么发给同事"里的命令补。

## 怎么发给同事

1. 把整个 `AI营销工具包` 文件夹发给同事（微盘共享/压缩包/直接拷都行）。
2. 告诉同事：**把里面的 `给AI的安装指令.md` 连同文件夹一起丢给他自己的 AI**，让 AI 自动装。
3. 同事用什么 AI 都行——Claude Code/CodeBuddy 装成常驻 skill；ChatGPT/Gemini 等存进自定义指令，安装指令里两条路都写了。

## 怎么用

装好后直接用自然语言提需求，AI 自己挑 skill：

```
"帮我优化这个落地页的转化率"     → 调 cro
"给 TikBit 写首页文案"       → 调 copywriting
"帮我想几个营销点子"            → 调 marketing-ideas
```

Claude Code 里也可以用斜杠命令点名：`/cro`、`/copywriting` 等。

**第一次用前**，先跑一遍 `product-marketing` 把产品档案建起来（比如 TikBit 或创业沙拉这条产品线的定位/目标用户/竞品/品牌调性）。没有这份档案，AI 写出来的东西就是放之四海皆准的废话；有了档案，输出才贴自己的产品。

### 产品档案存放位置

调用 `/product-marketing` 后会生成产品营销档案，**默认路径为**：  
`你的产品目录/营销资料/[产品营销档案].md`

这个路径是针对 TikBit 产品线定制的。如果你的项目结构不同，可以手动修改 `.claude/skills/product-marketing/skill.md` 里的路径配置（搜索路径并替换成你的项目结构）。

其他 9 个营销 skill（copywriting/cro/ai-seo 等）会自动读取这个档案作为上下文，确保所有营销产出都基于统一的产品定位和客户语言。

## 几个提醒

- **不是端到端自动化**：这些 skill 是顾问角色，能给方案、写文案、列检查清单，最后发广告/调价格/点发布按钮还是人自己做。
- **英文 SaaS 语境长出来的框架**：具体打法（尤其 social、cold email 那套）是海外路子，国内业务场景要自己改，骨架能用。
- **别整仓库全装**：46 个塞项目里一堆用不上的，翻目录反而添乱，按需装就够。
