# 企业微信接入 AI（Claude Code）· 部署手册 · 公开版

> **版本**：v2.1·公开版（2026-06-24，基于真实生产环境，含全套代码）
>
> **这份手册是什么**：教你（或你的 Claude Code）把**企业微信**接入跑在**你自己的云服务器**上的 Claude Code——人在外面、电脑关机也能用，同事可拉进群共用。支持文字、读文件、识图、生图、做文档/PPT、知识库记忆。
>
> **怎么用**：
> - **方式 A**：把这份手册整份发给你自己的 Claude，说"照着这份手册帮我在服务器上装"，它照着执行。
> - **方式 B**：你自己的工程师对着手册照做。
> 两种方式都要求这份文档**自包含、可照着执行**——所以下面把架构、决策、命令、全套代码、踩坑都写全了。
>
> **🔑 你需要自备一把大模型 API 密钥**：本方案不附带密钥。推荐到 **TikBit.ai** 注册申请一把自己的（支持 Claude 模型、识图、生图，国内直连稳定），拿到 `base_url` + `sk-` 开头的 key 后填进 §6 的密钥文件即可。也可用官方 Anthropic key 或其它支持 Claude 模型的中转。
>
> **💻 没有云服务器？** 企业微信**群聊机器人（智能机器人）走出站 WebSocket 长连接、免公网回调**，所以也能跑在一台常开的本地电脑上（不需要域名、不需要公网 IP）。只有**单聊**通道才必须公网+HTTPS+固定IP。**新手建议先只做群聊**，本地电脑即可起步。
>
> **凡是 `<尖括号>` 的都是占位符**，按你的实际信息替换（如 `<服务器IP>`、`<CorpID>`）。

## 0. 一句话讲清这套系统

让客户「人在外面、电脑关机」也能用 Claude Code：通过**企业微信**跟一个机器人对话，机器人在客户自己的服务器上调用 Claude Code 干活（读写文件、查资料、生图、做文档、记知识库），同事可拉进群共用。

**两个 Claude，分工不同（重要）**：

| 角色 | 是谁 | 干什么 | 边界 |
|------|------|--------|------|
| **运维 Claude** | 装机时握 SSH 的那个（我们，或客户工程师） | 装/改/升级这套系统本身 | 能改代码、动环境 |
| **业务 Claude** | 住在企业微信里、客户团队天天用的 | 用知识库工具干活 | **摸不到自己的代码和密钥** |

**铁律：运维 Claude 改造它，业务 Claude 不能改造自己**（自己改自己代码会把正在服务的进程搞挂）。

## 1. 装之前，先问客户要这些（前置清单）

**A. 服务器**
- 一台云服务器（阿里云/腾讯云/任意 Linux 均可），有公网 IP。建议 ≥2核4G、≥40G 盘。
- root SSH 权限。**先摸清：是不是生产机？跑着什么业务？** → 全程隔离进自己的 Docker 容器，**绝不碰客户现有业务**（网站目录、业务容器、数据库、其他 nginx 配置）。
- 一个**已备案的域名**（企业微信单聊回调要 HTTPS）。若只做群聊（智能机器人），**可不要域名**（走 WebSocket 长连接，免公网回调）。

**B. 企业微信后台（管理员权限）**
- 企业的 **CorpID**。
- 决定做哪条通道（**建议优先群聊**，见 §2）：
  - 群聊 → 建「智能机器人」，拿 **BotId + Secret**。
  - 单聊 → 建「自建应用」，拿 **AgentID + Secret + Token + EncodingAESKey**，并能配回调 URL、能把服务器 IP 加进「企业可信IP」。

**C. 大模型 API（自备一把）**
- **推荐**：到 **TikBit.ai** 注册申请一把自己的密钥（支持 Claude 模型、识图 vision、生图 gpt-image，国内直连稳定），拿到 `base_url`（形如 `https://tikbit.ai`）+ `sk-` 开头的 key。
- 也可用官方 Anthropic API key，或其它支持 Claude 模型的中转（若要识图，中转必须支持 vision）。
- 生图能力：复用同一把 key 即可（TikBit 同时支持 gpt-image 类模型）。
- ⚠️ 本手册**不附带任何密钥**，请用你自己申请的，费用走你自己的账户。

> **决策点**：只做群聊最省事（不要域名、不碰 nginx）。单聊体验更"私密"但要域名+公网+IP白名单。**新客户默认先上群聊**，单聊按需再加。

### 1.1 跨云适配（客户不一定在阿里云）

客户可能用腾讯云、AWS、华为云、自建 IDC……这套架构与云厂商无关（只要能跑 Docker），但有几处要按客户环境调：

| 关注点 | 阿里云（本手册默认） | 其他云怎么调 |
|--------|---------------------|------------|
| **镜像/包源** | Dockerfile 里换了阿里云 Debian 源 + 淘宝 npm 源 + 阿里云 pypi 源 | **海外服务器（AWS/GCP等）删掉这几处换源**，用默认源更快；腾讯云/华为云可换成各自的国内镜像源 |
| **安全组/防火墙** | 阿里云控制台「安全组」放行 | 每个云都有自己的安全组/防火墙面板（AWS=Security Group、腾讯云=安全组、华为云=安全组）。单聊要放行 **443**（HTTPS 回调）；群聊走出站长连接，**通常无需放行入站端口** |
| **公网 IP / IP 白名单** | 固定公网 IP，加进企业微信「可信IP」 | 有些云默认是动态/弹性 IP——**单聊必须绑定固定公网 IP**，否则 IP 变了企业微信白名单就失效。群聊不依赖固定 IP |
| **出站网络** | 能直连 api/中转 + 企业微信 | 确认服务器能出站访问：① 大模型 API/中转 ② 企业微信 `qyapi.weixin.qq.com` 和长连接网关。有的企业内网 IDC 出站受限，要先开通 |
| **Docker 安装** | 阿里云镜像市场或 yum/apt | 各云装 Docker 命令不同，按客户系统走官方文档 |

> **群聊（智能机器人）跨云最省心**：走出站 WebSocket 长连接，不需要公网入站、不需要域名、不需要碰防火墙入站规则——**给陌生云环境的客户，强烈建议先只上群聊**。单聊（需公网+HTTPS+固定IP+白名单）按需再加。

## 2. 架构总览

```
企业微信
 ├─ 单聊：自建应用 → 腾讯服务器回调 → nginx(HTTPS) → server.js(:8765, HTTP被动回调)
 └─ 群聊：智能机器人 → WebSocket长连接 ─────────────→ wsbot.js(主力，免公网)
                                                          ↓
                                            共享大脑：claude.js 调 Claude Code 子进程
                                                          ↓
                                            共享知识库 /workspace（= 服务器上 kb/）
```

- **单聊**走自建应用：腾讯把消息 POST 到你的回调 URL，需公网+HTTPS+nginx 反代+IP 白名单。
- **群聊**走智能机器人：SDK 主动连腾讯的 WebSocket，**免公网回调**，且**支持收文件**——所以是主力通道。
- 两通道**共享同一个大脑**（同一套 `claude.js` + `session.js`），知识库也是同一个 `/workspace`。

## 3. 关键架构决策（为什么这么设计，照抄即可）

| 决策 | 为什么 |
|------|--------|
| **用 Docker 隔离，不裸装** | 老系统（如 CentOS7 glibc 太旧）装不了新 Node；生产机裸装风险大。容器化 = 宿主机零改动，能力全隔离，绝不碰客户业务。 |
| **优先群聊（智能机器人）** | 自建应用在群里无身份；智能机器人专为群聊设计、长连接免公网、且支持收文件。 |
| **配置用 `CLAUDE.md` 不用 MEMORY.md** | Claude Code 只自动加载 `CLAUDE.md`。 |
| **Claude 子进程屏蔽企业微信密钥** | 防止有人通过对话把密钥套出来。子进程拿不到 token；要调企业微信 API，必须在 Node 桥接层调好再喂给 Claude。 |
| **识图绕开 Claude 的 Read** | 部分中转/环境下 Read 读图会瞎编。正解：桥接单独走 vision API 把图转成文字描述再喂 Claude。 |
| **容器内用非 root 用户(uid 1000)** | root 跑不了 Claude Code 的 `--dangerously-skip-permissions`。 |

## 4. 安装 SOP（从零到跑通，按步走）

> 全程由**运维 Claude 用 SSH** 操作。每一步都给了可直接执行的命令，占位符按客户信息替换。

### 步骤 0：摸清服务器、定目录
```bash
# 看系统、内存、磁盘、Docker 是否就绪
cat /etc/os-release | head -2; free -h; df -h /; docker --version
```
- 没装 Docker 先装（各发行版命令不同，略）。
- **约定根目录**：`/data/claude-workspace/`（与客户业务隔离）。下文统称 `$ROOT`。
```bash
ROOT=/data/claude-workspace
mkdir -p $ROOT/{kb,claude-home,bridge}
mkdir -p /root/claude-secrets   # 密钥目录，root-only
```

| 子目录 | 作用 | 容器内挂载点 |
|--------|------|------------|
| `$ROOT/kb` | 共享知识库（=业务 Claude 的工作区） | `/workspace` |
| `$ROOT/claude-home` | Claude 配置/skill 持久化 | `/home/node` |
| `$ROOT/bridge` | 桥接代码 | `/bridge` |
| `/root/claude-secrets` | 密钥（env 文件），**不进知识库** | 用 `--env-file` 注入 |

### 步骤 1：建镜像（见 §5 的 Dockerfile）
```bash
# 把 §5 的 Dockerfile 写到 $ROOT/Dockerfile，然后：
cd $ROOT && docker build -t claude-workspace:latest .
```

### 步骤 2：写密钥文件（见 §6 的四个 .env）
把 §6 的四个 env 文件写进 `/root/claude-secrets/`，按客户信息填值。

### 步骤 3：放桥接代码 + 装依赖（见 §7 全套代码）
```bash
# 把 §7 所有 .js / start.sh / package.json 写进 $ROOT/bridge/
cd $ROOT/bridge
docker run --rm -v $ROOT/bridge:/app -w /app claude-workspace:latest \
  npm install --registry https://registry.npmmirror.com   # 装 @wecom/aibot-node-sdk
chown -R 1000:1000 $ROOT/bridge $ROOT/kb $ROOT/claude-home
```

### 步骤 4：起容器（见 §8 的 run 命令）
按 §8 的 `docker run` 起 `claude-workspace`。

### 步骤 5：配企业微信
- **群聊（智能机器人）**：后台「管理工具→智能专区/AI+→智能机器人」，新建，连接方式选**长连接**，拿 BotId+Secret 填进 `wsbot.env`。无需公网回调，起容器即自动连上。
- **单聊（自建应用）**：后台建自建应用，配回调 URL = `https://<域名>/wecom-callback`，nginx 加反代（见 §9），并把**服务器公网 IP 加进「企业可信IP」**（否则发消息报 60020）。

### 步骤 6：写业务 `CLAUDE.md`（见 §10，**最关键、最易漏**）
把能力约定（发文件 `@FILE:`、发图 `@IMG:`、能力清单、触发方式）写进 `$ROOT/kb/CLAUDE.md`。**漏了这步，能力装了也不生效**（见 §11 致命教训）。

### 步骤 7：逐项实测（见 §12 验收清单）
收文件、发文件、发图、流式、新对话——**每个真发一遍**，别只做语法检查就说"已验证"。

## 5. Dockerfile（`$ROOT/Dockerfile`）

```dockerfile
FROM node:20-slim
# 国内服务器换阿里云 Debian 源（海外服务器可删这行）
RUN sed -i 's|deb.debian.org|mirrors.aliyun.com|g' /etc/apt/sources.list.d/debian.sources
# 基础工具 + Python 环境（生图等脚本需要）
RUN apt-get update && apt-get install -y --no-install-recommends \
    git ca-certificates procps \
    python3 python3-pip \
    && rm -rf /var/lib/apt/lists/*
# npm 换淘宝源（海外可删）+ 装 Claude Code
RUN npm config set registry https://registry.npmmirror.com \
    && npm install -g @anthropic-ai/claude-code
# Python 常用库（--break-system-packages 绕容器内 PEP668，容器隔离无风险）

CMD ["sleep", "infinity"]
```
> 海外服务器：删掉两处换源（aliyun/npmmirror），用默认源即可。

### 7.4 `session.js`（会话记忆 + 串行队列 + 待处理文件 + 重置命令）
```js
const fs = require('fs');
const FILE = '/bridge/sessions.json';
let map = {};
try { map = JSON.parse(fs.readFileSync(FILE, 'utf8')); } catch (e) {}
const queues = {};
const pendingFiles = {}; // userId -> [文件路径]

function getSession(userId) { return map[userId] || null; }
function setSession(userId, sid) {
  map[userId] = sid;
  try { fs.writeFileSync(FILE, JSON.stringify(map)); } catch (e) {}
}
function clearSession(userId) {
  delete map[userId];
  delete pendingFiles[userId];   // 开新对话也清掉没处理完的待上传文件
  try { fs.writeFileSync(FILE, JSON.stringify(map)); } catch(e){}
}
// 「开启新对话」关键词：必须整句精确匹配，避免误伤（如"新对话怎么开"不触发）
const RESET_CMDS = new Set([
  '新对话','开启新对话','开始新对话','新的对话','开新对话',
  '重新开始','重新对话','重开','重来','重新来',
  '清空上下文','清除上下文','清空对话','清除对话','清空记忆','清空历史','清除记忆',
  '重置','重置对话','重置上下文',
  '/new','/reset','/clear','new','reset','clear'
]);
function isResetCommand(text) {
  if (!text) return false;
  const s = String(text).trim().toLowerCase().replace(/[\s。.!！?？~～、,，:：]+$/g, '');
  return RESET_CMDS.has(s);
}
function enqueue(userId, task) {            // 串行队列：同一会话钥匙的任务排队跑，不撞车
  const prev = queues[userId] || Promise.resolve();
  const next = prev.then(task, task);
  queues[userId] = next.catch(() => {});
  return next;
}
function addPendingFile(userId, p) { (pendingFiles[userId] = pendingFiles[userId] || []).push(p); }
function takePendingFiles(userId) { const f = pendingFiles[userId] || []; delete pendingFiles[userId]; return f; }
module.exports = { getSession, setSession, clearSession, isResetCommand, enqueue, addPendingFile, takePendingFiles };
```

### 7.5 `claude.js`（调 Claude Code 子进程：普通版 + 流式版）
```js
const { spawn } = require('child_process');

// 普通版：等算完一次性返回 { result, sessionId, cost }。单聊用这个。
// 超时 900s(15分钟)：复杂生图/做带图PPT等多步任务实测需几分钟到十几分钟，给足头部空间。已有「停」命令可主动中断，不怕堵队列。
function askClaude(prompt, sessionId, { timeoutMs = 900000 } = {}) {
  return new Promise((resolve, reject) => {
    const args = ['-p', prompt, '--output-format', 'json', '--dangerously-skip-permissions'];
    if (sessionId) args.push('--resume', sessionId);
    // 安全:给 Claude 子进程过滤掉企业微信密钥(它用不到,挡住被套出来的可能)
    const env = { ...process.env };
    ['WX_CORP_ID','WX_AGENT_ID','WX_SECRET','WX_TOKEN','WX_AES_KEY','WX_ALLOW_USERS','WX_BOT_ID','WX_BOT_SECRET']
      .forEach(k => delete env[k]);
    const child = spawn('claude', args, { cwd: '/workspace', env });
    let out = '', err = '';
    const timer = setTimeout(() => { child.kill('SIGKILL'); reject(new Error('claude 超时')); }, timeoutMs);
    child.stdout.on('data', d => out += d);
    child.stderr.on('data', d => err += d);
    child.on('close', code => {
      clearTimeout(timer);
      if (code !== 0) return reject(new Error('claude 退出码 ' + code + ': ' + err.slice(0,200)));
      try {
        const j = JSON.parse(out);
        resolve({ result: j.result || '', sessionId: j.session_id || sessionId, cost: j.total_cost_usd || 0 });
      } catch (e) { reject(new Error('解析失败: ' + out.slice(0,200))); }
    });
  });
}

// 流式版：边算边吐。onProgress(actionText) 在每次工具调用时回调一次（群聊刷"正在做什么"）。
// 工具名 → 人话动作播报
const TOOL_LABEL = {
  Bash: '执行命令', Read: '读取文件', Write: '写文件', Edit: '修改文件',
  Glob: '查找文件', Grep: '搜索内容', WebFetch: '联网抓取网页', WebSearch: '联网搜索',
  Task: '调度子任务', TodoWrite: '梳理步骤', NotebookEdit: '编辑笔记本',
};
function friendlyAction(name, input) {
  const label = TOOL_LABEL[name] || ('调用 ' + name);
  const desc = input && (input.description || input.query || input.pattern
    || (input.file_path && require('path').basename(input.file_path))
    || (input.command && String(input.command).slice(0, 40)));
  return desc ? `${label}：${desc}` : label;
}
function askClaudeStream(prompt, sessionId, onProgress, { timeoutMs = 900000 } = {}) {

    child.stdout.on('data', chunk => {

        if (o.type === 'system' && o.session_id) sid = o.session_id;
        else if (o.type === 'assistant') {              // 完整工具调用在这里，带 name+input
          for (const c of (o.message && o.message.content) || []) {
            if (c && c.type === 'tool_use' && !seenTools.has(c.id)) {
              seenTools.add(c.id);
              try { onProgress && onProgress(friendlyAction(c.name, c.input)); } catch (_) {}
            }
          }
        } else if (o.type === 'result') {               // 最终答案（与 json 模式同字段）
          finalResult = o.result || ''; sid = o.session_id || sid; cost = o.total_cost_usd || 0;
        }
      }
    });
    child.stderr.on('data', d => err += d);
    child.on('close', code => {
      clearTimeout(timer);
      if (code !== 0) return reject(new Error('claude 退出码 ' + code + ': ' + err.slice(0, 200)));

  });
```

### 7.8 `wxcrypto.js`（单聊回调消息加解密，企业微信官方算法）
```js
const crypto = require('crypto');
// 企业微信回调消息加解密 (官方标准算法)
class WXBizMsgCrypt {
  constructor(token, encodingAESKey, receiveId) {
    this.token = token;
    this.key = Buffer.from(encodingAESKey + '=', 'base64'); // 解出 32 字节密钥
    this.iv = this.key.subarray(0, 16);                     // IV = 密钥前16字节
    this.receiveId = receiveId;                             // 企业ID(CorpID)
  }
  getSignature(timestamp, nonce, encrypt) {                 // sha1(排序拼接)
    const arr = [this.token, String(timestamp), String(nonce), encrypt].sort();
    return crypto.createHash('sha1').update(arr.join('')).digest('hex');
  }
  verify(signature, timestamp, nonce, encrypt) {
    return signature === this.getSignature(timestamp, nonce, encrypt);
  }
  _pad(buf) { const bs=32, p=bs-(buf.length%bs); return Buffer.concat([buf, Buffer.alloc(p,p)]); }
  _unpad(buf){ let p=buf[buf.length-1]; if(p<1||p>32)p=0; return buf.subarray(0, buf.length-p); }
  encrypt(msg) {                                            // 被动回复用
    const rnd = crypto.randomBytes(16);
    const m = Buffer.from(msg);
    const len = Buffer.alloc(4); len.writeUInt32BE(m.length, 0);
    const full = this._pad(Buffer.concat([rnd, len, m, Buffer.from(this.receiveId)]));
    const c = crypto.createCipheriv('aes-256-cbc', this.key, this.iv); c.setAutoPadding(false);
    return Buffer.concat([c.update(full), c.final()]).toString('base64');
  }
  decrypt(encrypted) {                                      // 收消息时用
    const d = crypto.createDecipheriv('aes-256-cbc', this.key, this.iv); d.setAutoPadding(false);
    const raw = this._unpad(Buffer.concat([d.update(Buffer.from(encrypted,'base64')), d.final()]));
    const content = raw.subarray(16);
    const msgLen = content.readUInt32BE(0);
    const msg = content.subarray(4, 4+msgLen).toString();
    const receiveId = content.subarray(4+msgLen).toString();
    return { msg, receiveId };
  }
}
module.exports = WXBizMsgCrypt;
```

```js
  const { buffer, filename } = await client.downloadFile(media.url, media.aeskey);
  fs.mkdirSync(INBOX, { recursive: true });
  const p = path.join(INBOX, filename || fb || (Date.now()+'.bin'));
  fs.writeFileSync(p, buffer); return p;
}
async function toText(b) {            // 取文本意图；mixed 合并文字+识别图；剥掉群里@前缀
  const t = b.msgtype; let s = '';
  if (t === 'text') s = (b.text && b.text.content) || '';
  else if (t === 'voice') s = (b.voice && b.voice.content) || '';
  else if (t === 'mixed') {
    const parts = [];
    for (const it of ((b.mixed && b.mixed.msg_item) || [])) {
      if (it.msgtype === 'text') parts.push(it.text.content);
      else if (it.msgtype === 'image') { const p = await saveMedia(it.image,'img.jpg'); try{ parts.push('[图片]'+await vision.describeImage(p,'')); }catch(_){ parts.push('[图片识别失败]'); } }
    }
    s = parts.join('\n');
  }
  return s.replace(/^(@\S+\s+)+/, '').trim();
}
async function buildPrompt(convKey, content, sender) {
  const files = session.takePendingFiles(convKey);
  let body = content;
  if (files.length) {
    const parts = [];
    for (const f of files) {
      const name = path.basename(f);
      if (isImage(f)) { try { parts.push(`图片「${name}」内容(自动识别)：\n${await vision.describeImage(f, content)}\n(原图：${f}，图生图作 --reference)`); } catch(e){ parts.push(`图片「${name}」识别失败：${e.message}`); } }
      else parts.push(`文件已保存：${f}（用合适的工具/skill 读取）`);
    }
    body = `用户上传了文件/图片：\n${parts.join('\n\n')}\n\n用户的指令：${content || '（未附文字，请先说明你读到了什么）'}`;
  }
  return sender ? `[发消息的人：${sender}]\n${body}` : body;
}
async function handle(frame) {
  const b = frame.body || {};
  const convKey = convKeyOf(b);
  const sender = (b.from && b.from.userid) || '未知';
  const t = b.msgtype;
  if (t === 'image' || t === 'file') {        // 单独发来文件：存为待处理 + 反问，不立刻调
    session.enqueue(convKey, async () => {
      const sid = generateReqId('stream');
      try {
        const p = await saveMedia(t === 'image' ? b.image : b.file, t === 'image' ? 'image.jpg' : 'file.bin');
        session.addPendingFile(convKey, p);
        await client.replyStream(frame, sid, acks.received(path.basename(p)), true);
      } catch (e) { try{ await client.replyStream(frame, sid, '收文件失败：'+e.message, true);}catch(_){} }
    });
    return;
  }
  session.enqueue(convKey, async () => {       // 文本/语音/图文：串行 → 流式 → 落定
    const sid = generateReqId('stream');
    const t0 = Date.now();
    const target = b.chattype === 'group' ? b.chatid : (b.from && b.from.userid);
    let ticker = null, closed = false;         // 提到 try 外，catch 也能清心跳防泄漏刷屏
    try {
      let quick = '';
      if (t === 'text') quick = (b.text && b.text.content) || '';
      else if (t === 'voice') quick = (b.voice && b.voice.content) || '';
      quick = quick.replace(/^(@\S+\s+)+/, '').trim();
      if (session.isResetCommand(quick)) {     // 开启新对话
        session.clearSession(convKey);
        try { await client.replyStream(frame, sid, '\u{2705} 已开启新对话，之前的上下文已清空～', true); } catch(_){}
        return;
      }
      // 流式：同一 streamId 持续刷"正在做什么"
      const actions = []; let lastNote = '正在思考…';
      const renderProgress = () => {
        const sec = ((Date.now() - t0) / 1000).toFixed(0);
        const tail = actions.slice(-4).map(a => '· ' + a).join('\n');
        return `🤔 ${lastNote}（已 ${sec} 秒）` + (tail ? `\n\n${tail}` : '');
      };
      try { await client.replyStream(frame, sid, renderProgress(), false); } catch(_){}   // 首帧开气泡
      ticker = setInterval(() => {              // 每2.5s刷一次(非阻塞,ack没回跳过防积压)
        if (closed) return;
        try { client.replyStreamNonBlocking(frame, sid, renderProgress(), false).catch(()=>{}); } catch(_){}
      }, 2500);
      const prompt = await buildPrompt(convKey, await toText(b), sender);
      const { result, sessionId } = await askClaudeStream(
        prompt, session.getSession(convKey),
        (action) => { actions.push(action); lastNote = action; }   // 工具调用→更新文案
      );
      closed = true; clearInterval(ticker);
      session.setSession(convKey, sessionId);
      const { text, images, files } = extractMedia(result);
      const answer = text || (images.length || files.length ? '好了，结果在下面👇' : '(空回复)');
      if (Buffer.byteLength(answer, 'utf8') > 19000) {   // 过长：气泡留短提示，正文主动发
        try { await client.replyStream(frame, sid, '答案较长，完整内容发你👇', true); } catch(_){}
        await client.sendMessage(target, { msgtype:'markdown', markdown:{ content: text } });
      } else {
        try { await client.replyStream(frame, sid, answer, true); }   // finish=true 落定
        catch(e){ if (text) await client.sendMessage(target, { msgtype:'markdown', markdown:{ content: text } }); }
      }
      for (const img of images) {               // 图片单独发(媒体进不了气泡)
        try {
          const up = await client.uploadMedia(fs.readFileSync(img), { type:'image', filename: path.basename(img) });
          await client.sendMediaMessage(target, 'image', up.media_id || up.mediaId);
        } catch(e){ try{ await client.sendMessage(target, {msgtype:'markdown', markdown:{content:'(图片发送失败：'+e.message+')'}}); }catch(_){} }
      }
      for (const file of files) {               // 文件单独发
        try {
          const stat = fs.statSync(file);
          if (stat.size > 20 * 1024 * 1024) throw new Error(`文件超过20MB限制(${(stat.size/1024/1024).toFixed(1)}MB)`);
          const up = await client.uploadMedia(fs.readFileSync(file), { type:'file', filename: path.basename(file) });
          await client.sendMediaMessage(target, 'file', up.media_id || up.mediaId);
        } catch(e){ try{ await client.sendMessage(target, {msgtype:'markdown', markdown:{content:'(文件发送失败：'+e.message+')'}}); }catch(_){} }
      }
      log(`已回复 ${convKey} (${sender}, ${((Date.now()-t0)/1000).toFixed(0)}s)`);
    } catch (e) {
      closed = true; if (ticker) clearInterval(ticker);   // 出错也停心跳
      const msg = /超时/.test(e.message)
        ? '这个有点复杂，我多花了点时间，可能已经弄好了——你发句"刚才那个好了吗"我确认下～'
        : '抱歉，刚才出了点岔子：' + e.message;
      try { await client.sendMessage(target, { msgtype:'markdown', markdown:{ content: msg } }); } catch(_){}
    }
  });
}
client.on('authenticated', () => log('\u{1F510} 智能机器人已连接并认证'));
client.on('error', e => log('连接错误:', e && e.message));
['message.text','message.image','message.file','message.voice','message.mixed'].forEach(ev => client.on(ev, handle));
client.connect();
log('启动中，连接企业微信长连接…');
```

## 11. 踩坑速查（别重走，结论版）

- **🩸 致命教训：能力 = 接收端代码 + 业务 Claude 知道怎么触发，缺一不可**。我们曾把"发文件"代码装好却不生效——因为业务 `CLAUDE.md` 里没写 `@FILE:` 标记约定，业务 Claude 不知道要输出标记，只会告诉用户"文件存在 /xxx"。**凡是靠标记/约定触发的能力，必须同步写进业务 CLAUDE.md（§10），否则等于没装。**
- **验证别夸大**：语法检查 ≠ 功能可用。每个能力都要真跑一遍端到端再说"已验证"。
- **改 nginx 铁律**：备份 → 改 → `nginx -t` → 过了才 reload，不过立刻还原。
- **企业微信发消息要 IP 白名单**：换 token 不查、发消息才查 IP。报 **60020** 就是服务器公网 IP 没加进「企业可信IP」。
- **容器内用非 root 用户**：否则 Claude Code 的 `--dangerously-skip-permissions` 跑不了。
- **知识库文件推上去后改属主**：容器跑 uid1000，文件 `chown 1000:1000` 否则读不了。
- **自建应用收不到 file**：单聊（自建应用）实测只推 image 不推 file；**智能机器人才支持收 file**。文件场景走群聊。
- **转发 ≠ 上传**：从网盘/聊天记录"转发"文件，企业微信服务器层直接拦截、不派给机器人；只有"上传"(附件/拖文件)才是真 `msgtype:file`。
- **长耗时任务别用被动回复等结果**：被动通道有窗口会超时。结果走主动发送(send 文字 + uploadMedia 拿 media_id + sendMediaMessage)。
- **流式被动通道实测能撑 322 秒+**（不是文档说的 5 秒，那只针对欢迎语/卡片）。用 `replyStreamNonBlocking` 节流防积压。
- **Read 读图会瞎编**：部分环境/中转下 Claude 的 Read 取不到图真实内容。走 `vision.js` 直连 vision API 识图，绝不让它用 Read 读图。
- **venv 别跨机器同步**：本地(Mac)建的 venv 软链接指向本地 python，传到 Linux 成空壳断链。venv 在服务器侧现建。
- **企业微信微盘/微文档 API 接入走不通**（权限墙、短docid 转不了长docid，已封档别试）。要给 AI 喂文件用 §14 的 Filebrowser 方案。

## 13. 群上下文：两种模式（装前问客户选）

改 `wsbot.js` 里 `convKeyOf` 一行即可切换：

| 模式 | 会话钥匙 | 效果 | 适合 |
|------|---------|------|------|
| **共享**（默认） | `wsg:群id` | 全群共用一个大脑/一条记忆线 | 一群人协作同一件事，上下文连贯 |
| **独立** | `wsg:群id + 人id` | 群里每人各自上下文，互不干扰 | 各问各的，怕串味 |

- 私聊本就按人id独立。两种模式都有**串行队列**保证不撞车，但要排队等（前一个长任务没跑完，后面等着）；每句话注入 `[发消息的人：X]` 防张冠李戴。
- 这是取舍不是对错——装前问客户"这个群主要协作还是各问各的"。

## 14. 可选增强：给 AI 喂文件的网页盘（Filebrowser）

企业微信微盘/微文档 API 走不通。要让同事方便地"上传文件给 AI 读"，可加个 Filebrowser 网页盘：
- 容器挂载根目录 = Claude 的 `/workspace`（kb/），同事网页上传 → 文件落 kb/ → Claude 立刻能读。
- nginx 加 `location /drive` 反代到它，带 `client_max_body_size 1024m` + `proxy_request_buffering off` 支持大文件。
```bash
docker run -d --name filebrowser --user 1000:1000 --restart unless-stopped \
  -v $ROOT/kb:/srv \
  -v $ROOT/filebrowser:/database \
  -v $ROOT/filebrowser/settings.json:/config/settings.json:ro \
  -p 127.0.0.1:8082:8080 filebrowser/filebrowser:latest
```
- **坑**：baseURL 必须靠挂载 `/config/settings.json`（写 `"baseURL":"/drive"`）设，env 和 `config set` 都会被镜像自带的覆盖。安全默认：禁陌生人注册、新用户只给 create+download 权限。
