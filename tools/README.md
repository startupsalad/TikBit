# 通用工具（可直接分享版）

> **✅ 这个目录的所有工具包都可以直接分享给同事使用。**

## 目录用途

存放**团队通用工具包**，包含 AI 助手能力扩展、文档处理、网页生成等工具。所有工具的密钥配置文件都已清空或使用示例占位符，可以安全地分享给同事。

## 分享给同事的标准流程

1. **确认工具包完整：** 检查 README/使用说明/安装指南是否齐全
2. **直接分享：** 通过企业微信微盘分享整个工具包文件夹
3. **告知同事：** 让同事把文件夹路径发给自己的 AI（Claude/CodeBuddy等），AI 会读取安装说明自动完成安装

## 密钥配置说明

- **已清空的配置文件：** `.env.example`、`config.example.json` 等示例文件，同事需要填入自己的密钥
- **需要密钥的工具：** AI客服工具包（Claude API）、PPT制作工具包（部分 Skill 需要 GPT API）
- **申请密钥：** 引导同事去 [https://tikbit.ai](https://tikbit.ai) 申请 API 密钥

## 注意事项

⚠️ **GPT工具包不在这里：** GPT 生图/做PPT 工具在 `../通用工具_已安装配置/GPT工具包/`（包含熊哥密钥，仅供 AI 调用，不分发）。如果同事需要 GPT 工具，应从 `GPT工具包/分发包（给同事下载）/` 获取打包好的 zip。
