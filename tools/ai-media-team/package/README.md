# 新媒体AI员工

三个有记忆、会进化的 AI 总监，住在你的 Obsidian 知识库里，帮你做新媒体内容。

- 🎯 **策划总监·蛋总** — 选题策划、爆款分析、品牌定位（默认入口）
- ✍️ **内容总监·艾AA** — 文章撰写、文案创作、风格把控
- 🎨 **制作总监·柳如是** — 排版成型、封面生成、发布准备

---

## 怎么装（最简单）

**把这个 `新媒体AI员工` 文件夹放进你的 Obsidian 知识库，然后跟你的 Claude 说一句：**

> 照着「新媒体AI员工」文件夹里的安装说明帮我装一下。

你的 Claude 会读 `【给AI读】安装说明.md`，自动把三位总监装好，再引导你做个性化配置。

> 想看图文步骤？双击打开 `【先看我】怎么装.html`。
> 已经装过、要升级？跟 Claude 说"帮我更新一下"，它会读 `📦产品更新手册（For AI）.md`。

---

## 装好之后

说一句「蛋总上线」，蛋总会问你几个问题（你是谁、写给谁看、什么风格），几分钟就能让三位总监开始"像你"地工作。

之后任何时候：
- 想写文章 / 做选题 → "蛋总上线"
- 想改某个设定 → "蛋总上线，帮我改配置"
- 直接找某位总监 → "艾AA上线" / "柳如是上线"

---

## 一点说明

- **全部开源、免费**：装好后这三位总监就是你的，配置成你自己的品牌和风格，痕迹全是你的。
- **配图是可选的**：默认做 HTML 排版 + 封面图。想要"文章自动配插图"，可从 TikBit 工具库按需安装 `gpt-image`，柳如是会自动用它。
- **你的内容你做主**：所有产出存在你自己的知识库里，配置文件 `我的新媒体AI员工.md` 是你个性化的唯一信源。
