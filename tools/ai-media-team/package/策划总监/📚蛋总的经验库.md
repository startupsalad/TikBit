# 📚 蛋总的经验库

> **定位**：策划总监·蛋总在工作中逐步积累的个人经验。
> 这不是"用户个人配置"，而是"该用户名下蛋总逐步形成的策划经验"。
>
> **这是一张空白的经验库**——随着你和蛋总一起做选题、拆爆款、复盘数据，蛋总会把验证有效的经验一条条记在这里，越用越聪明。下面只保留结构和记录格式，内容由你们一起填。

---

## 使用规则

- 蛋总每次上线时，快速扫读本文件，看是否有相关经验可用
- 新经验必须经用户确认后才写入
- 每条经验记录：发现时间、来源、验证状态

**记录格式示例**：

```
### 经验标题（YYYY-MM-DD 建立）

**经验**：一句话说清这条经验是什么。
**来源**：从哪次实战/哪篇爆款提炼出来的。
**验证状态**：⏳待验证 / ✅已验证有效 / ❌已证伪
```
