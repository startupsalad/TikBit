# 🎯 对标账号库

> **归属**：蛋总(策划总监)的核心工作素材
> **核心理念**：学结构、学套路、学钩子；**不抄观点、不抄案例、不抄人设**。
>     对标账号是脚手架，里面的砖必须是你自己的故事和洞察。
>
> **这是一个空白的库**——你来决定对标哪些头部账号，蛋总帮你把它们的套路拆开、内化。下面是方法和结构，账号由你自己加。

---

## 一、为什么有这个库?

新媒体内容生产线如果只闭门造车，会很快陷入"自嗨"。**对标头部账号是最快的进化方式**——它们已经用真金白银验证过什么能爆、什么不能爆。我们站在它们的肩膀上，把套路拆开、内化、再用**你自己的故事和处境**重组，产出"形似而神不似"的原创内容。

---

## 二、库该长什么样?

每对标一个账号，就在本文件夹下建一个子文件夹：

```
🎯对标账号库/
├── README.md                  ← 当前文件
└── 账号名/                     ← 你要对标的某个头部账号
    ├── 账号画像.md             ← 账号定位、风格、选题地图、套路指纹
    ├── 套路提炼.md             ← 从爆款中沉淀的可复用套路库
    └── 爆款档案/
        └── YYYYMMDD-标题.md    ← 每篇爆款一份完整档案
```

### 文件类型说明

| 文件 | 作用 | 更新频率 |
|------|------|---------|
| **账号画像.md** | 账号定位、风格、选题地图、套路指纹的整体描述 | 每抓 5-10 篇就重新校准一次 |
| **套路提炼.md** | 从所有爆款档案中沉淀的可复用套路库(标题公式/开头模型/结构骨架/金句模式) | 持续累加 |
| **爆款档案/** | 单篇爆款的完整存档:原文 + 三种分析(可借鉴内容/经验提炼/可选高拟合改写) | 每抓一篇加一份 |

> **怎么选对标账号**：挑 1-3 个跟你**领域相近、但已经做得很好**的账号。可以分类型挑——比如一个"快讯型"(学抓热点)、一个"文笔型"(学有温度地写)、一个"专业型"(学建立可信度)。挑好后告诉蛋总，他帮你建画像、拆套路。

## 三、怎么用这个库?

### 工作流:从抓取到使用

```
你给出公众号 + 时间范围 (或直接给爆款链接)
        ↓
[微信推文-内容获取工具.py] 抓取原文到内存
        ↓
[微信推文-分析和内化工具] 三种分析模式
   ├─ 模式1:可借鉴内容 → 存爆款档案
   ├─ 模式2:经验提炼 → 同步沉淀到三总监经验库
   └─ 模式3:高拟合改写(可选) → 记入选题库
        ↓
归档到对应账号的「爆款档案/」
        ↓
每抓 5-10 篇后,刷新该账号的「套路提炼.md」
        ↓
持续校准「账号画像.md」
        ↓
**蛋总每次做选题时,自动读取本库 → 找参照 → 给选题建议**
```

### 命名规范

**爆款档案文件名**:`YYYYMMDD-标题简版.md`
- 例如:`20260515-某AI产品刚刚突然.md`
- 日期 = 公众号文章的**发布日期**(不是抓取日期)
- 标题取主标题前 10-15 字,去掉敏感符号

### 三种分析模式选择规则

| 场景 | 默认执行的模式 |
|------|--------------|
| 单纯学习这篇文章 | 模式1 + 模式2 |
| 这篇文章我想改写成自己的 | 模式1 + 模式2 + 模式3 |
| 短平快盘点账号 | 仅模式1 |

## 四、套路提炼怎么沉淀?

每个账号的「套路提炼.md」分四块:

1. **标题公式库**:统计该账号最爱用的标题结构(感叹号/反问/数字/人物视角等),给出可套用模板
2. **开头模型库**:前 200 字的钩子模式(故事开场/痛点开场/反常识开场)
3. **结构骨架库**:整篇文章的搭建逻辑(起承转合/平铺直叙/反复横跳)
4. **金句模式库**:被高频转发的句式特征(对仗/反差/口语化金句)

**重要**:每条套路必须标注**适用场景**和**不适用场景**——不是所有套路都适合你的灵魂风格。

---

## 五、对标账号库 vs 三总监经验库

| 维度 | 对标账号库 | 三总监经验库 |
|------|----------|-------------|
| 关注点 | **谁**这么做的(账号画像) | **怎么做**(操作技巧) |
| 组织方式 | 按账号分类 | 按职能分类(策划/创作/制作) |
| 更新方式 | 抓爆款时归档 | 每次实操后沉淀 |
| 调用场景 | 选题策划阶段(蛋总主用) | 全流程(三总监都用) |

两者**互相喂养**:每篇爆款拆完,经验同步进经验库;经验库越厚,以后看新爆款理解得越快。

## 六、谁能改这个库?

- **新增账号**:你决策,Claude 执行建文件夹
- **删除账号**:你明确指令,Claude 才能删
- **更新画像/套路**:Claude 可以基于新抓的爆款主动更新,**但要告诉你改了什么**
- **新增爆款档案**:Claude 自动归档,无需确认
