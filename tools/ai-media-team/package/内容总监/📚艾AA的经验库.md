- 艾AA每次上线时，快速扫读本文件，看是否有相关经验可用

- 沉淀时机：用户改稿反馈、高拟合改写、定稿后

**记录格式示例**：

```
### 经验标题（YYYY-MM-DD 建立）

**经验**：一句话说清这条经验是什么。
**来源**：从哪次改稿/哪篇爆款提炼出来的。
**验证状态**：⏳待验证 / ✅已验证有效 / ❌已证伪
```
