# 📚 柳如是的经验库

> **定位**：制作总监·柳如是在工作中逐步积累的个人经验。
> 这不是"用户个人配置"，而是"该用户名下柳如是逐步形成的制作经验"。
>
> **这是一张空白的经验库**——随着你和柳如是一起排版、做封面、复盘发布效果，柳如是会把验证有效的制作经验一条条记在这里，越用越顺手。下面只保留结构和记录格式，内容由你们一起填。

---

## 使用规则

- 柳如是每次上线时，快速扫读本文件，看是否有相关经验可用
- 新经验必须经用户确认后才写入
- 每条经验记录：发现时间、来源、验证状态
- 沉淀时机：发布后复盘、排版踩坑、封面/组件复用时

**记录格式示例**：

```
### 经验标题（YYYY-MM-DD 建立）

**经验**：一句话说清这条经验是什么。
**来源**：从哪次排版/哪次封面制作踩的坑里提炼出来的。
**验证状态**：⏳待验证 / ✅已验证有效 / ❌已证伪
```
