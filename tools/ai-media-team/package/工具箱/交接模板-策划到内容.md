# 交接模板:策划总监→内容总监

> **使用方法**:蛋总完成选题策划后,复制对应平台的模板,填充信息,然后把完整brief交给艾AA。
> **原则**:每个字段必须填,空着或写"待定"=策划工作没完成,不能交棒。
> 
> **存放规则**:
> - 填好的策划文件存放位置:`新媒体AI员工/策划总监/策划总监作品/`
> - 文件命名格式:`[选题标题] 策划.md`
> - 示例：`Claude Opus 4.7 策划.md`

---

## 📧 模板1:微信推文Brief

```markdown
# [选题标题] · 微信推文Brief

**交棒时间**:YYYY-MM-DD HH:MM
**蛋总(策划总监)** → **艾AA(内容总监)**

## 一、选题基本信息

- **标题**:[确定版或3个候选]
- **字数**:2000-2500字(具体目标数)
- **平台**:公众号
- **发布时间**:YYYY-MM-DD(预计)
- **读者画像**:[目标用户是谁、他们的痛点]
- **核心论点**:[一句话说清楚这篇文章要证明什么]

## 二、文章框架

### 开篇([字数])

- **角度**:[反直觉/场景带入/直接抛观点/slogan式]
- **素材**:[用什么素材]
- **关键句**:[需要突出的句子]

### Part 1:[小标题+emoji]([字数])

- **核心论点**:[这个板块要证明什么]
- **素材清单**:
  - 素材1:[来源+用在哪]
  - 素材2:[来源+用在哪]
- **核心概念**:[如果有,比如 AI Fusion(人机融合)]
- **落地**:[这个板块最后收束的一句话]

### Part 2:[小标题+emoji]([字数])

(同上格式)

### 结尾([字数])

- **收束方式**:[不问"你想XX"/回到开头/金句点睛]
- **金句**:[结尾的关键句子]
- **转化**:[是否带转化/轻度/重度]
- **转化文案建议**:[如需转化,一句话建议]

## 三、格式要求

- [ ] 每个板块必须有小标题+emoji(参考配置文件Part 2.8)
- [ ] 英文词汇2-3个,每个加中文解释(参考配置文件Part 2.1)
- [ ] 关键句按加粗4原则标注(参考配置文件Part 2.9)
- [ ] 核心张力至少体现一个(参考配置文件Part 2.3)

## 四、风险提示(如有)

- [ ] 是否涉及敏感信息(财务、私人)?如何处理?
- [ ] 是否有AI味陷阱?(某些话题容易写成鸡汤)
- [ ] 是否需要特别注意的禁忌词?

## 五、蛋总自检

- [ ] 选题方向明确
- [ ] 核心论点清晰
- [ ] 素材齐全(每个板块有具体素材)
- [ ] 结构合理(字数、板块数)
- [ ] 格式要求写清
- [ ] 转化目标明确
- [ ] 符合配置文件Part 1硬规则
```

## 通用原则

**所有brief必须保证的事:**

1. **艾AA拿到brief后,不需要再问蛋总任何问题就能开始写**——brief不完整=策划工作没完成
2. **素材必须具体**——不能写"可以引用一些名人名言",要写"引用纳瓦尔的XXX"
3. **字数必须具体**——不能写"适中",要写"2200字"
4. **风险必须预警**——如果有敏感内容、禁忌词雷区,必须提前标注

**什么时候可以留空?**

- 艾AA可以灵活发挥的细节(具体句式、过渡句写法)
- 标题候选(如果蛋总给了3个,让艾AA从中选或基于此发挥)

**什么时候必须填?**

- 所有带⬜checkbox的字段
- 所有"字数"、"来源"、"目标"类字段
