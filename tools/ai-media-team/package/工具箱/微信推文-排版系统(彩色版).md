# 推文排版系统（彩色版）

> **适用场景**：课程推广文、活动宣传文、产品介绍文等需要色彩丰富、视觉活泼的微信公众号推文。
> **与黑绿白版的区别**：黑绿白版（`文章生成系统.md`）适合个人IP内容、深度思考文；彩色版适合课程/活动/产品宣传，视觉冲击力更强。
> **封面图工具**：`脚本工具/微信推文生成封面图工具_彩色版.py`

---

## 何时选用彩色版 vs 黑绿白版

| 维度 | 黑绿白版（Phosphor Jade） | 彩色版（Multi-Gradient） |
|------|---------------------------|--------------------------|
| 适用内容 | 个人IP文章、深度思考、经验分享 | 课程宣传、活动推广、产品介绍 |
| 视觉感觉 | 克制、高级、科技感 | 活泼、丰富、有吸引力 |
| 主色 | `#00D900` 亮绿 | `#8B5CF6` 紫色（+ 多色系） |
| 品牌定位 | 痞帅思想深邃 | 专业可信赖 + 活力 |
| 正文风格 | 娓娓道来、情绪驱动 | 结构化、信息密度高 |

### 容器

```html
<div class="wrapper" style="max-width:580px; margin:0 auto; padding:20px 15px; font-family:-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Hiragino Sans GB', 'Microsoft YaHei', sans-serif;">
```

### 分隔线

彩色版分隔线用 50px 宽的紫色色块：

```html
<p style="text-align:center; margin:25px 0;">
  <span style="display:inline-block; width:50px; height:3px; background:#8B5CF6; border-radius:2px;"></span>
</p>
```

## HTML结构模板

### 基础骨架

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<style>
  body { display:flex; justify-content:center; background:#f5f5f5; margin:0; padding:20px; }
  .wrapper { max-width:580px; width:100%; background:#fff; padding:20px 15px; }
</style>
</head>
<body>
<div class="wrapper">
  <!-- 所有内容，每个元素必须写完整内联style -->
</div>
</body>
</html>
```

> **注意**：`<style>` 标签中的样式仅用于本地浏览器预览（居中显示、灰色背景），复制到微信公众号后台时会被剥离。实际复制的内容是 `<div class="wrapper">` **内部**的所有HTML，外层的 `body`、`<style>` 不会进入微信。因此外层预览代码可以用 flex 等微信不支持的属性，不影响推文效果。

### 大标题

```html
<p style="font-size:28px; font-weight:900; color:#1a1a1a; line-height:1.3; margin-bottom:5px; text-align:center;">
  标题文字
</p>
<p style="font-size:15px; color:#64748B; text-align:center; margin-bottom:25px;">
  副标题或一句话描述
</p>
```

### 章节标题

```html
<p style="font-size:20px; font-weight:700; color:#1a1a1a; line-height:1.5; margin:30px 0 15px;">
  🔥 章节标题
</p>
```

### 正文段落

```html
<p style="font-size:15px; color:#475569; line-height:1.9; margin-bottom:15px;">
  正文内容。<strong style="color:#1a1a1a;">加粗文字</strong>用深色强调。
</p>
```

### 步骤卡片（用 table 实现）

```html
<table width="100%" cellpadding="0" cellspacing="0" style="border-collapse:collapse; margin:0 0 6px 0;">
  <tr>
    <td style="padding:12px 16px; border-left:3px solid #0EA5E9; background:#eef8ff;">
      <p style="margin:0 0 4px 0; font-size:15px; font-weight:700; color:#1a1a1a; line-height:1.6;">
        <span style="display:inline-block; background:#0EA5E9; color:#fff; font-size:11px; font-weight:700; padding:2px 8px; border-radius:3px; margin-right:8px;">STEP 1</span>
        步骤名称
      </p>
      <p style="margin:0; font-size:13px; color:#64748B; line-height:1.6;">
        步骤说明文字
      </p>
    </td>
  </tr>
</table>
```

> 5个步骤依次使用 `#0EA5E9` → `#06B6D4` → `#8B5CF6` → `#EC4899` → `#F43F5E` 配色。

### Part/课程板块卡片

```html

  <tr>
    <td style="padding:18px 20px; background:#f8fafc; border:1px solid #e2e8f0; border-top:3px solid #0EA5E9;">
```

## 微信兼容性规则（必须严格遵守）

### 必须做

1. **每个标签写完整内联 style** — 不依赖父容器继承，微信编辑器会剥离
2. **需要背景色的卡片用 `<table>`** — `<div>` 的 background 在复制粘贴时会丢失
3. **`<table>` 加三属性** — `cellpadding="0" cellspacing="0" style="border-collapse:collapse"`
4. **每个 `<td>` 写完整内联样式** — padding、background、border 等全部写在 style 里
5. **`<meta charset="UTF-8">`** — 防中文乱码
6. **列表用手写符号 + padding-left 缩进** — `<p style="padding-left:16px;">• 内容</p>` 代替 `<ul>/<ol>`
7. **水平排列用 `inline-block + vertical-align:middle`** — 不用 flexbox
8. **多边框差异化用属性叠加** — `border:1px solid #e2e8f0; border-top:3px solid #0EA5E9` 后者覆盖前者的顶边，实现顶部强调色
9. **双栏间距用空 `<td>` 占位** — `<td width="4%"></td>` 代替 margin/gap
10. **行内彩色标签用 `<span>` 而非 `<div>`** — `<span style="display:inline-block; background:#0EA5E9; color:#fff; padding:2px 8px;">STEP 1</span>`（`<span>` 可以用 background，`<div>` 不行）
11. **留白用 `&nbsp;` 段落** — `<p style="line-height:2;">&nbsp;</p>` 做顶部空间，防止 margin 被微信吞掉
12. **分隔线用空 `<span>`** — `<p style="text-align:center;"><span style="display:inline-block; width:50px; height:3px; background:#8B5CF6;"></span></p>` 代替 `<hr>`（`<hr>` 样式不可控）

### 禁止用

1. ❌ `display:flex` / `flexbox` / `grid`
2. ❌ `<style>` 中的类选择器（样式必须全部内联）
3. ❌ `<div>` 带 `background`（改用 `<table>`）
4. ❌ `<ul>` / `<ol>` 标签
5. ❌ CSS 变量 `var(--xxx)`（写死具体值）
6. ❌ `@media` 媒体查询
7. ❌ `transform` / `animation` / `transition`
8. ❌ `rgba()` 颜色值用在 `<td>` 上（改用 HEX 实色）
9. ❌ `border-radius` 用在 `<td>` 上（微信不支持）
10. ❌ `background-clip:text`（渐变文字在微信中不显示）
11. ❌ `<hr>` 标签（样式不可控，用空 `<span>` 画彩色短横线代替）

### 踩坑记录

- **Write工具创建HTML文件可能出现中文乱码** — 应使用Read+Edit方式修改现有HTML文件
- **连接线在微信中变成全宽色条** — `<table>` 没有设定 width 会撑满，解决：用紧贴排列的步骤卡片代替连接线
- **`<td>` 上的 `rgba()` 和 `border-radius` 不生效** — 改用 HEX 实色，去掉圆角
- **图片必须先上传到微信后台** — HTML 中的本地图片路径在公众号中不可用

## 封面图生成

### 两种风格

彩色版封面提供**深色底**和**浅色底**两种选择：

| 风格 | 背景 | 适用场景 |
|------|------|----------|
| **深色底**（推荐） | `#0B0F1A` → `#1a1035` → `#0f1a2e` 深蓝紫渐变 | 朋友圈/信息流中更醒目 |
| **浅色底** | `#FAFBFF` → `#f0f0ff` 浅蓝白 | 清新风格，适合教育类 |

### 封面规格

- **尺寸**：900×383px（公众号头条封面标准，2.35:1）
- **输出**：2x 高清（1800×766px）
- **安全区**：中间 383×383px 正方形（分享时裁切为卡片封面）
- **渐变色**：三色渐变 `#0EA5E9`（天蓝）→ `#8B5CF6`（紫色）→ `#F43F5E`（玫瑰红）

### 使用方式

1. 修改脚本顶部 CONFIG 区域的文字内容
2. 设置 `STYLE = "dark"` 或 `STYLE = "light"` 选择深色/浅色底
3. 运行脚本生成封面图

```bash
python3 "🔧规范和工具/新媒体内容生产线系统/脚本工具/微信推文生成封面图工具_彩色版.py"
```

### 封面文字布局

```
LINE1 — 主标题（渐变色/纯色大字）
LINE2 — 副标题（白色/深色大字）
────── 装饰线 ──────
LINE3 — 说明行1
LINE4 — 说明行2（渐变色/强调色）
─────────────────────
TAG1   TAG2   TAG3  ← 底部标签
```

## 完整工作流

1. **确定内容** — 准备好文章正文、标题、结构
2. **选择版本** — 彩色版（本文档）或 黑绿白版（`文章生成系统.md`）
3. **生成正文HTML** — 按上述排版规范生成微信兼容的HTML
4. **生成封面图** — 运行封面脚本，选择深色底/浅色底
5. **复制到微信** — 浏览器打开HTML → 全选复制 → 粘贴到公众号编辑器
6. **设置封面** — 上传生成的封面图
7. **检查预览** — 手机预览确认排版正确
