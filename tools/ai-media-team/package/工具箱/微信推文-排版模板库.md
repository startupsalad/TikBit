# 微信推文排版模板库

> **定位**：微信公众号HTML排版的可复用代码模板库。所有模板都经过微信编辑器兼容性测试，可直接复制使用。
>
> **使用前提**：必须先阅读制作总监skill中的「微信编辑器兼容性规则」，理解为什么要这样写。
>
> **⚠️ 重要**：本模板库使用占位符表示品牌色，制作总监（柳如是）在使用时会自动替换为用户配置文件中的品牌色。

---

## 占位符说明

模板中使用以下占位符表示品牌色，使用时会自动替换为用户配置的品牌色：

| 占位符 | 含义 | 示例（默认绿色系） |
|--------|------|-------------------|
| `{{PRIMARY_COLOR}}` | 品牌主色 | {{PRIMARY_COLOR}} |
| `{{ACCENT_COLOR}}` | 品牌强调色（加粗文字） | {{ACCENT_COLOR}} |
| `{{PRIMARY_LIGHT}}` | 品牌浅色（分隔线等） | {{PRIMARY_LIGHT}} |
| `{{PRIMARY_BG}}` | 品牌背景色（卡片背景） | {{PRIMARY_BG}} |
| `{{PRIMARY_BORDER}}` | 品牌边框色 | {{PRIMARY_BORDER}} |

**通用色**（不使用占位符，所有用户通用）：
- 红色系（`#c0392b`、`#fff5f5`）- 风险/警告
- 绿色系（`#27ae60`、`#f0faf0`）- 安全/推荐（通用，非品牌色）
- 蓝色系（`#2c6fbb`、`#f0f5fa`）- 对比/信息
- 灰色系（`#e0e0e0`、`#f5f5f5`）- 中性/背景

## HTML骨架模板

每个公众号排版HTML文件的基础结构：

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>文章标题</title>
<style>
  body { margin:0; padding:20px; background:#f5f5f5; display:flex; justify-content:center; }
  .wrapper { max-width:580px; background:#fff; padding:30px 24px; font-family:-apple-system,BlinkMacSystemFont,"PingFang SC","Hiragino Sans GB","Microsoft YaHei",sans-serif; }
</style>
</head>
<body>
<div class="wrapper">
  <!-- 所有内容放这里，每个元素必须有完整内联样式 -->
</div>
</body>
</html>
```

**注意**：
- `<meta charset="UTF-8">` 不能省略，否则中文乱码
- `<style>` 标签只用于浏览器预览，复制到公众号后会被剥离
- 所有内容元素必须有完整内联样式

## 基础文本元素

### 文章大标题

```html
<h1 style="font-size:22px;font-weight:bold;color:#333;text-align:left;margin:0 0 25px;line-height:1.5;">文章标题</h1>
```

### 板块大标题（带emoji + 左边框）

```html
<h2 style="font-size:20px;font-weight:bold;color:{{PRIMARY_COLOR}};border-left:4px solid {{PRIMARY_COLOR}};padding-left:12px;margin:30px 0 20px;line-height:1.5;">🦞 板块标题</h2>
```

### 编号小标题

```html
<h3 style="font-size:16px;font-weight:bold;color:{{PRIMARY_COLOR}};margin:25px 0 15px;line-height:1.5;">1. 小标题</h3>
```

### 正文段落

```html
<p style="font-size:15px;color:#555;line-height:2;margin:0 0 18px;">正文内容，每个段落都要有完整的内联样式。</p>
```

### 加粗强调

```html
<strong style="color:{{ACCENT_COLOR}};">关键词或核心观点</strong>
```

### 引用块

```html
<table cellpadding="0" cellspacing="0" style="width:100%;border-collapse:collapse;margin:20px 0;">
<tr><td style="background:{{PRIMARY_BG}};border-left:3px solid {{PRIMARY_COLOR}};padding:15px 20px;border-radius:4px;">
<p style="font-size:15px;color:#666;font-style:italic;margin:0;line-height:2;">引用的文字内容</p>
</td></tr>
</table>
```

### 分隔线（✦ 符号 + 两侧横线）

```html
<p style="text-align:center;margin:30px 0;">
<span style="display:inline-block;width:40px;height:1px;background:{{PRIMARY_LIGHT}};margin:0 8px;vertical-align:middle;"></span>
<span style="color:{{PRIMARY_COLOR}};font-size:12px;vertical-align:middle;">✦</span>
<span style="display:inline-block;width:40px;height:1px;background:{{PRIMARY_LIGHT}};margin:0 8px;vertical-align:middle;"></span>
</p>
```

**关键**：必须用 `inline-block` + `vertical-align:middle`，禁止用 flexbox。

### 列表项（模拟 <ul>）

```html
<p style="font-size:15px;color:#555;line-height:2;margin:0 0 8px;padding-left:20px;">• 列表项一</p>
<p style="font-size:15px;color:#555;line-height:2;margin:0 0 8px;padding-left:20px;">• 列表项二</p>
<p style="font-size:15px;color:#555;line-height:2;margin:0 0 18px;padding-left:20px;">• 列表项三</p>
```

**注意**：不使用 `<ul>/<ol>` 标签，微信兼容性差。

## 图示卡片模板

### ① 左右对比卡片（最常用）

**适用场景**：两个事物的直接对比（风险vs安全、旧方式vs新方式）

**设计要点**：
- 两栏各50%宽度，间距3px
- emoji 22px，标题13-14px，列表项12px
- 文字精简到不换行或最多换一行

```html
<table cellpadding="0" cellspacing="0" style="width:100%;border-collapse:collapse;margin:15px 0;">
  <tr>
    <td style="width:50%;vertical-align:top;padding:0 3px 0 0;">
      <table cellpadding="0" cellspacing="0" style="width:100%;border-collapse:collapse;">
        <tr><td style="background:#fff5f5;padding:12px 10px;border:1px solid #f0d0d0;">
          <p style="font-size:22px;margin:0 0 4px;text-align:center;line-height:1.2;">🚫</p>
          <p style="font-size:13px;font-weight:bold;color:#c0392b;margin:0 0 8px;text-align:center;line-height:1.4;">左侧标题</p>
          <p style="font-size:12px;color:#666;margin:0 0 4px;line-height:1.6;">• 要点一</p>
          <p style="font-size:12px;color:#666;margin:0;line-height:1.6;">• 要点二</p>
        </td></tr>
      </table>
    </td>
    <td style="width:50%;vertical-align:top;padding:0 0 0 3px;">
      <table cellpadding="0" cellspacing="0" style="width:100%;border-collapse:collapse;">
        <tr><td style="background:#f0faf0;padding:12px 10px;border:1px solid #c0e0c0;">
          <p style="font-size:22px;margin:0 0 4px;text-align:center;line-height:1.2;">✅</p>
          <p style="font-size:13px;font-weight:bold;color:#27ae60;margin:0 0 8px;text-align:center;line-height:1.4;">右侧标题</p>
          <p style="font-size:12px;color:#666;margin:0 0 4px;line-height:1.6;">• 要点一</p>
          <p style="font-size:12px;color:#666;margin:0;line-height:1.6;">• 要点二</p>
        </td></tr>
      </table>
    </td>
  </tr>
</table>
```

**常用配色方案**：

| 对比类型 | 左侧背景 | 左侧边框 | 左侧标题色 | 右侧背景 | 右侧边框 | 右侧标题色 |
|---------|---------|---------|----------|---------|---------|----------|
| 风险 vs 安全 | `#fff5f5` | `#f0d0d0` | `#c0392b` | `#f0faf0` | `#c0e0c0` | `#27ae60` |
| 旧方式 vs 新方式 | `#f5f5f5` | `#ddd` | `#999` | `{{PRIMARY_BG}}` | `{{PRIMARY_BORDER}}` | `{{PRIMARY_COLOR}}` |
| A产品 vs B产品 | `{{PRIMARY_BG}}` | `{{PRIMARY_BORDER}}` | `{{PRIMARY_COLOR}}` | `#f0f5fa` | `#d0e0f0` | `#2c6fbb` |

## 使用建议

1. **每篇文章2-4个图示卡片**：不要连续放两个，中间隔1-2段文字
2. **优先使用左右对比卡片**：视觉冲击力最强，手机上效果最好
3. **文字要精简**：手机屏幕窄，每栏只有约170px宽
4. **颜色要有含义**：红色=风险，绿色=推荐，灰色=中性
5. **复制前检查**：确保所有颜色值、字号、间距符合配置文件中的品牌规范
