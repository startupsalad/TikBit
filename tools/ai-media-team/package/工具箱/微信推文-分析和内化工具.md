# 微信推文-分析和内化工具

> **用途**：抓取微信推文后，立即执行分析和内化，产出三样东西：
> 1. 经验 → 直接写入三位总监经验库
> 2. 可复用素材（金句/段落/结构/标题公式）→ 写入素材原料库
> 3. 高拟合改写标记 → 记入选题库
>
> **不是脚本**，是 Claude 执行的工作流文档。抓取完成后紧接着执行，不保存原文。

---

## 输入

- 「微信推文-内容获取工具.py」抓取到内存中的正文 Markdown + 元数据
- 不保存原文到文件，分析完直接产出结果

---

## 三种分析模式

用户可单选或组合使用。默认全部执行。

### 模式1：可借鉴内容

**输出文件**：`分析-可借鉴内容.md`

**分析维度**：

| 维度 | 具体拆解 |
|------|---------|
| 标题公式 | 用了什么公式？为什么吸引人？可套用的模板 |
| 开篇方式 | 前3句话怎么抓人？悬念/痛点/反常识/场景？ |
| 结构分段 | 几个板块？每个板块的功能（铺垫/论证/转化）？ |
| 节奏 | 长短句交替？情绪起伏？高潮在哪？ |
| 用词密度 | 关键词重复频率？口语化程度？ |
| 转化动作 | 在哪里引导？用什么话术？硬度如何？ |
| 可直接借鉴章节 | 哪些段落/结构可以直接搬到我们的内容中？ |

**输出格式**：
```markdown
---
source_entry: "YYYYMMDD-编号"
analysis_type: "可借鉴内容"
analysis_time: "YYYY-MM-DD HH:MM"
---

# 可借鉴内容分析

## 标题公式
...

## 开篇方式
...

## 结构分段
...

## 节奏分析
...

## 用词密度
...

## 转化动作
...

## 可直接借鉴的章节
（标注原文位置 + 借鉴方式）
```

### 模式2：高拟合改写

**输出文件**：`分析-高拟合改写.md`

**核心原则**：保留原文的"方向、角度、语气、结构、节奏、用词密度、逻辑、感觉"，但用本系统的品牌声音重新组织输出。

**执行步骤**：
1. 读取 `原文.md` 全文
2. 读取 `CONFIG`（`新媒体AI员工/我的新媒体AI员工.md`）的 Part 2 风格偏好 + Part 3 灵魂风格
3. 逐段改写：
   - 保留：段落功能（铺垫/论证/转化）、信息密度、情绪走向
   - 替换：案例换成用户自己的经历、口吻换成用户的写作风格、品牌信息替换
4. 自检：改写后的文章，读起来像"用户自己写的"而不是"抄的"

**输出格式**：
```markdown
---
source_entry: "YYYYMMDD-编号"
analysis_type: "高拟合改写"
analysis_time: "YYYY-MM-DD HH:MM"
---

# 高拟合改写

> 原文：《原标题》by 原作者
> 改写保留：方向、角度、语气、结构、节奏、用词密度、逻辑、感觉

## 改写标题建议
1. ...
2. ...
3. ...

## 改写正文

（完整改写内容）
```

### 模式3：经验提炼

**输出文件**：`分析-经验提炼.md`

**核心原则**：把从这篇文章中学到的经验，分发到策划/内容/制作三条经验轨道。

**执行步骤**：
1. 读取 `原文.md` + `分析-可借鉴内容.md`（如果已生成）
2. 读取经验萃取方法论：`🔧规范和工具/📋规范/AI协作规范/经验萃取方法论.md`
3. 按三条轨道提炼：
   - 🎯 策划经验（蛋总）：选题角度、标题技巧、受众定位、内容结构策略
   - ✍️ 创作经验（艾AA）：文案技巧、开头方式、转化话术、语气把控
   - 🎨 制作经验（柳如是）：排版风格、视觉节奏、图片使用、组件复用
4. **先展示给用户判断**，用户确认后才写入对应经验库

**输出格式**：
```markdown
---
source_entry: "YYYYMMDD-编号"
analysis_type: "经验提炼"
analysis_time: "YYYY-MM-DD HH:MM"
---

# 经验提炼

## 🎯 策划经验（→ 蛋总经验库）

1. **[经验标题]**：[是什么] / [为什么有效] / [怎么用]
   - 来源：本文 [具体段落/结构]
   - 状态：待验证

## ✍️ 创作经验（→ 艾AA经验库）

1. **[经验标题]**：...

## 🎨 制作经验（→ 柳如是经验库）

1. **[经验标题]**：...

---

> ⚠️ 以上经验需用户确认后，才会写入对应总监的经验库。
```

**经验沉淀路径**：
- 策划经验 → `新媒体AI员工/策划总监/📚蛋总的经验库.md`
- 创作经验 → `新媒体AI员工/内容总监/📚艾AA的经验库.md`
- 制作经验 → `新媒体AI员工/制作总监/📚柳如是的经验库.md`

## 触发场景

### 场景A：用户直接给微信链接，要抓取+分析

```
用户："分析这篇微信文章 https://mp.weixin.qq.com/s/xxx"
    ↓
1. 调用 微信推文-内容获取工具.py 抓取到内存
2. 立即执行分析（默认全部三种产出）
3. 经验 → 展示给用户确认后写入总监经验库
4. 可复用素材 → 写入素材原料库
5. 判断是否适合高拟合改写 → 建议用户，确认后记入选题库
6. 更新链接收集箱"已处理"
```

### 场景B：蛋总处理收集箱时发现微信链接

```
蛋总处理 1️⃣链接收集箱
    ↓
发现 mp.weixin.qq.com 链接
    ↓
自动走本工具流程（抓取 + 分析，一气呵成）
    ↓
产出经验、素材、高拟合改写建议
```

### 场景C：用户指定高拟合改写

```
用户："这篇文章做高拟合改写"
    ↓
抓取原文 → 直接记入选题库（来源类型：高拟合改写，附原文链接）
    ↓
等用户决定要写时，艾AA重新抓取原文执行改写
```

## 对标账号库联动(2026-05-19 新增)

**当抓取的微信文章来源于对标账号**(AGI Hunt / 数字生命卡兹克 / 新智元)时,**额外动作**:

1. **归档**:把这篇爆款的原文+三种分析存到 `BENCHMARK_LIB/对应账号/爆款档案/YYYYMMDD-标题简版.md`
2. **画像校准**:每抓 5-10 篇后,基于真实数据重写该账号的 `账号画像.md`,标注"已校准"
3. **套路累加**:把发现的新套路追加到该账号的 `套路提炼.md`(标题公式 / 开头模型 / 结构骨架 / 金句模式 四块)
4. **经验同步**:经验提炼的内容,**同时**沉淀到三总监经验库 + 该账号的`套路提炼.md`

**判断账号归属**:
- 微信文章顶部的"原创/公众号名"字段 → 决定归到哪个账号文件夹
- 不在对标账号库内的微信文章 → 走标准流程,不归对标账号库
