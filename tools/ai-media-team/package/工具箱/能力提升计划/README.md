# 📚 三位总监能力提升计划

> **核心理念**:三位总监不是"一次性设定",而是会持续学习、持续进化的AI员工。
> 每位总监对应50本领域经典 + 持续的案例学习,读一本沉淀一次方法论。

---

## 为什么要做这件事

这是我们产品的**核心护城河**和**最大宣传亮点**:

1. **普通AI vs 我们的AI**:别人的AI是"一问一答",我们的AI是"读过50本经典、看过500个案例"
2. **可视化成长**:每次产品更新,附带"三位总监又读了哪些书"的进度
3. **学员认同**:学员不是"买了一个工具",是"雇了三个在持续学习的专业人"

## 学习节奏

**建议节奏**:每位总监每月读2-3本,持续积累。

**每本书的沉淀流程**:
1. **读完**:用户或Claude快速过一遍关键章节
2. **提取**:抓出3-5条可落地的方法论
3. **沉淀**:写入对应总监的工具箱方法论文件
4. **引用**:在对应skill里加上引用(如 `内容总监skill → 击穿式文案方法论.md`)
5. **记录**:在本计划的"已读"部分标注日期+核心收获

## 如何选书?

**策划总监**:选题方法论经典、爆款研究、内容战略、用户心理学、数据分析
**内容总监**:文案经典、小说/散文名著、广告创意、深度写作、心理学
**制作总监**:设计经典、审美理论、色彩学、信息可视化、字体学

**原则**:
- 优先中文经典(作者是中国人或面向中国市场),这样学到的方法论更本土化
- 优先经典(30年+或已被验证),不追新书
- 优先方法论类,次选理论类
- 优先案例丰富的,少选抽象理论
