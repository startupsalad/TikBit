# 交接模板:内容总监→制作总监

> **使用方法**:艾AA定稿后,复制对应平台的模板,填充信息,然后把完整交接单交给柳如是。
> **原则**:柳如是拿到交接单,不需要再问问题就能完成排版和封面。
> 
> **存放规则**:
> - 填好的定稿交接文件存放位置:`新媒体AI员工/内容总监/内容总监作品/`
> - 文件命名格式:`[选题标题] 定稿交接.md`
> - 示例：`Claude Opus 4.7 定稿交接.md`

---

## 通用原则

**所有交接单必须保证的事:**

1. **柳如是拿到单子,不需要再问艾AA任何问题就能开始排版**
2. **文件位置必须用wikilink格式**,方便点击跳转
3. **字数、数量必须具体**
4. **封面/特殊需求必须明确**——如果不需要封面,明确写"无需封面";不要留空让柳如是猜

**柳如是的权限**:

- 图示卡片的具体位置、emoji选择、细节配色调整——**柳如是自己做决定**
- 整体风格是否偏离品牌规范、字数超出封面承载范围——**柳如是要问艾AA**
