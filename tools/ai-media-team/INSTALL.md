# 📦 新媒体AI员工 · 安装说明（给 AI 读）

> **这份说明是给「用户电脑里的 Claude」看的，不是给人看的。**
> 用户把这个文件夹交给你、说一句"照着安装说明帮我装"，你就照本说明把整套「新媒体AI员工」装好，并引导用户完成个性化配置。

---

## 第零原则：你是一个聪明的安装者，不是脚本复读机

1. **先观察环境**：先搞清楚你在哪、这个文件夹在哪、用户的知识库（vault）根目录在哪。
2. **优先走标准路径**：按下面"标准安装"四步走。
3. **遇阻用你自己的知识灵活解决**：路径不对就找，文件夹没在 vault 里就提示用户拖进来，skill 目录不存在就创建。
4. **守住安全底线**：只复制/移动本产品的文件；绝不删除或覆盖用户已有的笔记、配置、密钥。每一步都要可逆。
5. **失败两次就换思路**：同一个方法失败两次，停下来说清楚卡在哪、换个方式，别硬撞。

---

## 这个产品是什么

「新媒体AI员工」= 三个有记忆、会进化的 AI 总监，长期住在用户的知识库里，帮他做新媒体内容：

| 员工 | 职责 | 怎么喊它 |
|------|------|---------|
| 🎯 策划总监·蛋总 | 选题策划、爆款分析、品牌定位与配置管理（默认入口） | "蛋总上线" / "帮我做选题" / "修改配置" |
| ✍️ 内容总监·艾AA | 文章撰写、文案创作、风格把控 | "艾AA上线" / "帮我写文章" |
| 🎨 制作总监·柳如是 | 排版成型、封面生成、发布准备 | "柳如是上线" / "帮我排版" |

三个员工是 skill，装好后用户说出需求就自动上线。

> **⭐ 双模型（Claude + GPT 都能用）**：Claude 和 GPT(Codex) 用同一套 Agent Skills 标准（SKILL.md），所以三位总监**同时装进 `~/.claude/skills/`（Claude）和 `~/.codex/skills/`（GPT）**，配置文件和作品都在知识库里共享。用户在对话框上方选哪个大脑，三位总监都能上线。（写长文时 Claude 与 GPT 各有风格，用户可自行择优——两个都能用。）

## 标准安装（四步）

### Step 1：把产品文件夹放进用户的知识库

本工具的 `package/` 目录就是产品文件夹（安装到知识库后命名为 `新媒体AI员工`，里面有 `我的新媒体AI员工.md`、`策划总监/`、`内容总监/`、`制作总监/`、`工具箱/`、`📦临时skill文件夹/`）。

把 `package/` 整个目录复制到**用户知识库（vault）的根目录**下，并将目标目录命名为 `新媒体AI员工`。

- 如果你正运行在用户的知识库里，vault 根目录就是当前工作目录。
- 如果用户是从下载文件夹解压的，先确认解压位置，再复制进 vault 根目录。
- 复制后确认：`ls "新媒体AI员工/"` 能看到上面那些文件/文件夹。

> ⚠️ 文件夹名就用 `新媒体AI员工`（不带任何前缀符号）。三个 skill 内部都按这个名字找文件。

### Step 2：安装三个总监 skill

把 `📦临时skill文件夹/` 里的三个总监复制到 Claude 的 skills 目录，**统一用英文名**（避免和中文名冲突）：

**⭐ 装两处**：`~/.claude/skills/`（Claude 读）和 `~/.codex/skills/`（GPT 读）。同一份 skill 拷两份即可。

**Mac / Linux：**
```bash
for base in "$HOME/.claude/skills" "$HOME/.codex/skills"; do
  mkdir -p "$base"
  cp -r "新媒体AI员工/📦临时skill文件夹/策划总监" "$base/marketing-director"
  cp -r "新媒体AI员工/📦临时skill文件夹/内容总监" "$base/content-director"
  cp -r "新媒体AI员工/📦临时skill文件夹/制作总监" "$base/creative-director"
done
```

**Windows（在 Claude Code 的 bash 环境里）：**
```bash
for base in "$HOME/.claude/skills" "$HOME/.codex/skills"; do
  mkdir -p "$base"
  cp -r "新媒体AI员工/📦临时skill文件夹/策划总监" "$base/marketing-director"
  cp -r "新媒体AI员工/📦临时skill文件夹/内容总监" "$base/content-director"
  cp -r "新媒体AI员工/📦临时skill文件夹/制作总监" "$base/creative-director"
done
```

验证：`ls ~/.claude/skills/ | grep director` 和 `ls ~/.codex/skills/ | grep director` 都应看到 `marketing-director`、`content-director`、`creative-director` 三个。
> 若这台电脑没装 GPT(Codex)、没有 `~/.codex/` 目录，跳过 `~/.codex/skills/` 那份即可（只装 Claude 侧不影响使用）。

### Step 3：清理临时文件

skill 装好后，临时文件夹和本说明就没用了，删掉保持知识库干净：

```bash
rm -rf "新媒体AI员工/📦临时skill文件夹"
rm -f "新媒体AI员工/【给AI读】安装说明.md"
rm -f "新媒体AI员工/【先看我】怎么装.html"
rm -f "新媒体AI员工/📦产品更新手册（For AI）.md"
```

（更新手册先留着，老用户更新时还会用到——若用户是全新安装，可一并删除。）

### Step 4：登记到 CLAUDE.md 和 AGENTS.md（如果有）

在用户知识库根目录的 `CLAUDE.md`（Claude 读）**和 `AGENTS.md`（GPT 读）** 末尾，各追加同样这一小段（让以后每次对话、不管用哪个大脑都知道这套系统在）：

```markdown
## 新媒体AI员工系统

- 产品位置：`新媒体AI员工/`
- 配置文件：`新媒体AI员工/我的新媒体AI员工.md`（个性化唯一信源）
- 三个角色通过 skill 自动触发：策划总监·蛋总 / 内容总监·艾AA / 制作总监·柳如是
- 所有产品规则、流程由 skill 和 `新媒体AI员工/工具箱/` 内部管理
```

哪个文件没有就跳过哪个（两个都没有也行——skill 一样会触发）。

## 安装到底做了什么（万一上面的命令跑不通，照这个手动做）

1. 把 `新媒体AI员工/` 整个文件夹放到用户 vault 根目录。
2. 把里面 `📦临时skill文件夹/` 的三个子文件夹，分别复制到 `~/.claude/skills/` **和 `~/.codex/skills/`** 下（两处各一份），命名为 `marketing-director`（策划总监）、`content-director`（内容总监）、`creative-director`（制作总监）。每个文件夹里有一个 `SKILL.md`。（没有 `~/.codex/` 目录就只装 Claude 侧。）
3. 删掉 `新媒体AI员工/📦临时skill文件夹` 和两份说明文件。
4. 就这些。没有任何脚本要跑、没有任何依赖要装。

## 装完：引导用户完成个性化配置（最重要的一步）

skill 装好只是"请来了三位总监"，但他们还**不认识用户**。配置文件 `新媒体AI员工/我的新媒体AI员工.md` 现在是一张空白模板。

装完后，主动对用户说（照这个意思说，用你自己的话）：

```
✅ 新媒体AI员工装好了！三位总监已就位：策划总监·蛋总、内容总监·艾AA、制作总监·柳如是。

不过他们还不认识你。说一句「蛋总上线」，蛋总会问你几个问题
（你是谁、想写给谁看、想用什么风格），几分钟就能让三位总监开始"像你"地工作。
```

蛋总被唤起后会自动检测到配置文件为空，进入"首次配置引导"，把答案写回 `我的新媒体AI员工.md`。

**额外提示用户**（可选但很加分）：配置文件里有个 **Part 3 🧬 灵魂风格**——填得越用心（或让蛋总/艾AA帮忙一起梳理），写出来的东西越像"本人写的"，而不是"AI写的"。

## 关于 AI 配图（模块化·可选，不装也能用）

本产品**默认不带生图脚本**，柳如是默认做 HTML 排版 + 封面图，已经能交付完整内容。

如果用户想要"文章自动配插图"，可以**另外**从 TikBit 工具库安装 `gpt-image`：
- 装了之后，柳如是会自动检测到（`~/.claude/gpt-image/config.json`）并调用它配图。
- 没装也完全不影响——柳如是会在插图位留占位框，不报错。

不要因为缺生图工具就报错或中断，这是设计内的可选项。

## 排错（用户说"用不了""不上线"时，你来当售后）

按这个顺序排查：

1. **skill 没触发**（说"蛋总上线"没反应）：
   - 查 `ls ~/.claude/skills/ | grep director`（GPT 侧查 `ls ~/.codex/skills/ | grep director`），三个在不在。
   - 都在的话，让用户**新开一个对话/重启**（skill 在启动时加载，刚装的需要新会话才生效）。
2. **上线了但没头像**：头像在 `新媒体AI员工/工具箱/📦素材库/品牌素材/{蛋总,艾AA,柳如是}.png`。确认文件夹是否完整复制进了 vault。找不到头像不影响功能，会用纯文字上线。
3. **总监说找不到配置文件**：确认 `新媒体AI员工/我的新媒体AI员工.md` 在 vault 根目录下、文件夹名没带多余前缀。
4. **排版/封面脚本报缺依赖**：封面脚本用 Playwright（`pip install playwright && playwright install chromium`）。这是可选的高级功能，缺了不影响写文章；按需引导用户安装即可。
5. **生图相关**：见上面"关于 AI 配图"——缺生图工具是正常的，不是 bug。

排查时遵守安全底线：只读不乱删，任何要删/要改用户数据的动作先问用户。

## 重装 / 卸载

- **重装**：重跑"标准安装"四步即可，skill 会被覆盖到最新；**不会动**用户的配置文件和作品。
- **卸载**：删除 `~/.claude/skills/` **和 `~/.codex/skills/`** 下的 `marketing-director`、`content-director`、`creative-director` 三个文件夹 + 删除 vault 里的 `新媒体AI员工/` 文件夹。删 vault 文件夹前**务必提醒用户**：里面有他的配置和作品，建议先备份。
