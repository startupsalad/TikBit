# WeChat deployment

The complete deployment guides are installed locally. Read `resources/INSTALL.md`, then the selected `resources/personal/部署手册.md` or `resources/enterprise/部署手册.md`. Installation of this package does not mean a remote server is deployed. First collect the user's server/domain and chosen WeChat integration type. Keep credentials in the user's own local configuration, never in chat or Git. Do not reuse the workstation token on a remote service. Obtain task-specific authorization before remote changes or sending messages. Help with the deployment directly; do not ask the user to copy skill files or run installation commands themselves.
