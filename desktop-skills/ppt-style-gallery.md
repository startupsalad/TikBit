# PPT style gallery

Read `resources/README.md`. The gallery's complete templates and supporting assets are installed beside this Skill under `resources`. Locate its style-picker HTML and serve the resources through a local HTTP server bound to 127.0.0.1, then open that local URL; do not use file:// because iframe previews require HTTP. Keep the server's exact process handle and stop only that server when the preview is no longer needed. Use the installed template as the starting point for the user's deck. Preserve attribution and licenses. Do not say the gallery needs downloading again.
